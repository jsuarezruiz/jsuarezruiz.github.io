Remarks

Use immediate writes to scrub values directly from input for dragging, scroll linking, and carousels. A write interrupts animation on the touched channels, and a follow-up spring inherits its optional velocity: Motion.Jump(track).X(pointerX, velocity); Motion.Animate(track).X(snap).With(spring).Start();
