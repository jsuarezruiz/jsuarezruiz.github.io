AlongPath(AvaloniaObject, MotionPath, MotionTiming, Point, bool)

Move a control along a path instead of straight to a point. The path is sampled by arc length, so the control keeps an even speed through tight curves.

public static MotionHandle AlongPath(AvaloniaObject target, MotionPath path, MotionTiming timing, Point offset = default, bool orient = false)

Parameters

target AvaloniaObject

The control to move; its x and y channels are driven.

path MotionPath

Path to follow, in the same coordinate space as the control's translation.

timing MotionTiming

How progress along the path is animated.

offset Point

Added to every point, for centring the control on the path.

orient bool

Whether to rotate the control to the path heading.
