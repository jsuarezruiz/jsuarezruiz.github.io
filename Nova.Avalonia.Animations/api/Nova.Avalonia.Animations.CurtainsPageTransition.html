Remarks

Implements Avalonia's Avalonia.Animation.IPageTransition for navigation and content controls.

<NavigationPage>
  <NavigationPage.PageTransition>
    <nova:CurtainsPageTransition Pattern="Blinds" Panels="8" />
  </NavigationPage.PageTransition>
</NavigationPage>
