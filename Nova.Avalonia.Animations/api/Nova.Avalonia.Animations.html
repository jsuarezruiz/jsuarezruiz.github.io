A physics-based spring. Unlike easing-based springs it has no fixed duration: it runs until it physically settles, and it preserves velocity when an in-flight animation is retargeted.

How long a spring takes to settle. Springs have no duration of their own, so a sequence needs an estimate to know when the next step should start.
