Getting started

Prerequisites

  • Avalonia 12 or later
  • .NET 8 or later

Install the core package

Run this command from your application project:

dotnet add package Nova.Avalonia.Animations

Install the optional shader package only when the application uses SkSL effects:

dotnet add package Nova.Avalonia.Animations.Shaders

Add the XAML namespace

No style registration is required for the motion engine. Add the Nova namespace to any view that uses attached motion properties or Nova controls:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:nova="https://nova.avaloniaui.net">
    <Border Width="180"
            Padding="20"
            Background="#7C3AED"
            CornerRadius="16"
            nova:Motion.WhileHover="scale:1.05; y:-6"
            nova:Motion.WhilePress="scale:0.96">
        <TextBlock Text="Move me" Foreground="White" />
    </Border>
</UserControl>

Compact XAML states accept x, y, scale, scaleX, scaleY, rotate, rotateX, rotateY, depth, opacity, and delay entries separated by semicolons or commas.

Start an animation from C#

Import the namespace, choose the destination channels, select timing, and call Start on the UI thread:

using Nova.Avalonia.Animations;

await Motion.Animate(Card)
    .X(120)
    .Y(-8)
    .Scale(1.05)
    .Opacity(1)
    .With(Spring.Bouncy)
    .Start();

Springs are the default timing, so .With(Spring.Default) can be omitted. Use a tween when duration is the important part of the design:

await Motion.Animate(Card)
    .X(0)
    .Rotate(0)
    .With(Tween.Css(0.35, "cubic-bezier(0.22, 1, 0.36, 1)"))
    .Start();
