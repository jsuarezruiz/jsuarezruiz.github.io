Fluent animations

Begin with Motion. A MotionBuilder collects channels for one target and starts them together.

Transform channels

var handle = Motion.Animate(Card)
    .X(140)
    .Y(-20)
    .Scale(1.08)
    .Rotate(4)
    .RotateY(-10)
    .Depth(700)
    .Opacity(0.95)
    .With(Spring.Snappy)
    .Start();

Transform channels compose onto Nova's render transform. A later call targeting only X does not cancel a running opacity or scale channel.

Avalonia properties

Use Property for any supported styled or attached property:

Panel.Background = Brushes.MediumSlateBlue;

Motion.Animate(Panel)
    .Property(Border.CornerRadiusProperty, new CornerRadius(28))
    .Property(Border.BackgroundProperty, Brushes.MediumPurple)
    .With(Spring.Smooth)
    .Start();

Nova includes interpolation for numbers, Point, Vector, Size, Rect, Thickness, CornerRadius, Color, and solid brushes. Register an application-specific value type at startup with Interpolators.

Immediate writes

Motion.Jump writes a channel immediately and interrupts an animation already controlling it. It is useful for scrubbing and direct pointer tracking.

Motion.Jump(Card).X(pointerX).Y(pointerY).Rotate(tilt);

Read transform channel state with Motion.GetX, GetY, GetScaleX, GetScaleY, GetRotate, GetRotateX, GetRotateY, and GetDepth.

Playback control

Start returns an awaitable MotionHandle.

var playback = Motion.Animate(Card)
    .X(0, 180, 360)
    .Y(0, -56, 0)
    .With(Tween.EaseInOut(1.2))
    .Start();

playback.Pause();
playback.Seek(0.5);
playback.Resume();

await playback;

Reverse and Seek require a finite, non-repeating handle. Stop leaves channels at their current values, while Complete writes their final values. CancelWhen(token) stops playback when the token is cancelled.

If only part of a handle is interrupted, seeking updates its remaining channels and skips those that have already ended. It cannot overwrite a replacement animation on an interrupted channel.

Playback mutations must run on the Avalonia thread.
