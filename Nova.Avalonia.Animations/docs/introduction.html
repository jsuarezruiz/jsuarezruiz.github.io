Introduction

Nova.Avalonia.Animations provides a small set of composable motion primitives instead of replacing Avalonia's control system. Animations write independent transform or property channels, while controls, bindings, templates, input, and accessibility remain owned by Avalonia.

Core design

  • Independent channels. Translation, scale, rotation, depth, opacity, and Avalonia properties can run together without replacing one another.
  • Interruption is normal. Retargeting a spring keeps the current channel velocity instead of beginning again from rest.
  • One timing model. Spring and Tween work across fluent animations, interactions, values, layout, and composed samples.
  • Awaitable playback. MotionHandle represents one or several running channels and exposes playback controls.
  • Optional effects. The SkSL implementation lives in a separate package so the core library has no shader dependency.

Packages

Nova.Avalonia.Animations contains the motion engine, XAML behaviours, layout projection, path and text helpers, page transitions, and packaged styles.

Nova.Avalonia.Animations.Shaders adds ShaderView, ShaderBackdrop, ShaderTransition, built-in shaders, and skeleton styles. It references the core package.
