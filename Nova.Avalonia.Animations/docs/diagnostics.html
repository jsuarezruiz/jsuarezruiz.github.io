Reduced motion and diagnostics

Disable nonessential motion

Set IsEnabled to false when the application or user preference requests reduced motion. New animations immediately apply their final values, preserving the final visual and logical state.

MotionConfig.IsEnabled = !userPrefersReducedMotion;

Apply the preference before creating views when possible, and update it if the operating-system preference changes while the application is running.

Inspect timing in slow motion

MotionConfig.Speed is a positive global multiplier. Values below one slow the engine, which is useful for finding discontinuities, incorrect origins, and one-frame flashes.

MotionConfig.Speed = 0.2;

Restore it to 1 outside diagnostics. Invalid, zero, negative, or non-finite values throw.

Route recoverable diagnostics

Nova reports invalid compact-state entries, ignored configuration, and completion callback failures without terminating the animation engine.

MotionConfig.Diagnostic += (_, args) =>
    logger.LogWarning("Nova motion: {Message}", args.Message);

The shader package has an independent event because compilation occurs in composition handlers:

ShaderDiagnostics.Diagnostic += (_, args) =>
    logger.LogWarning("Nova shader: {Message}", args.Message);

Shader diagnostics are marshalled back to the Avalonia thread.

Test motion deterministically

Use the public completion task or await the handle instead of sleeping for a guessed duration. For UI tests that need an intermediate frame, pause or seek a finite handle and assert the channel values through Motion.GetX, GetY, and the other channel readers.
