Timing

Every animation uses a MotionTiming. Choose a spring when motion should react naturally to interruption and a tween when it must follow a fixed duration and easing curve.

Springs

Spring runs until its position and velocity reach their rest thresholds. It has no fixed duration.

var timing = new Spring
{
    Stiffness = 420,
    Damping = 30,
    Mass = 1,
};

Motion.Animate(Card).X(240).With(timing).Start();

The built-in presets are Default, Smooth, Snappy, Bouncy, and Stiff. Spring.Perceptual(visualDuration, bounce) creates a spring from design-oriented duration and bounce values.

var settle = Spring.Perceptual(0.5, bounce: 0.12);

When another animation targets the same channel, the new spring inherits its current value and velocity. This is especially useful for pointer, selection, and layout interactions.

Tweens

Tween has a fixed Duration and Avalonia Easing.

Motion.Animate(Banner)
    .Opacity(1)
    .With(Tween.EaseOut(0.24))
    .Start();

Use Linear, EaseIn, EaseOut, or EaseInOut for common curves. Tween.Css accepts names such as ease-out and cubic Bézier values:

var timing = Tween.Css(0.4, "cubic-bezier(0.16, 1, 0.3, 1)");

Delay and repeat

Both timing types inherit these options:

Property Meaning
Delay One-time delay before the first cycle
Repeat Extra cycles; 0 plays once and -1 repeats forever
RepeatMode Loop snaps to the beginning; Reverse alternates direction
RepeatDelay Pause between cycles 
var pulse = new Tween
{
    Duration = 0.7,
    Repeat = -1,
    RepeatMode = RepeatMode.Reverse,
    RepeatDelay = 0.1,
};

Motion.Animate(StatusDot).Scale(1.18).With(pulse).Start();

Use SpringEstimate when a sequence or diagnostic needs a spring's estimated settle time.
