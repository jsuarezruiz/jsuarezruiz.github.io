Nova.Avalonia.AIKit

Welcome to Nova.Avalonia.AIKit

Nova.Avalonia.AIKit is a provider-agnostic suite of controls for building AI-native applications with Avalonia. It provides production-oriented UI for chat, streaming responses, agent activity, human approval, tool calls, code review, retrieval, model selection, and usage dashboards.

Start here

  • Introduction explains the library's scope and design.
  • Getting started installs the package, registers NovaTheme, and creates a first prompt experience.
  • Theming and motion covers base themes, resource overrides, dark mode, and reduced motion.
  • Control guides group the controls into practical AI workflows.

Control areas

Area Included controls
Conversation ChatMessageList, ChatComposer, StreamingTextBlock, FollowUpList, PromptBar
Agent activity ThinkingTrace, LoadingIndicator, AgentAvatar, AgentTaskRow, AgentTimeline, MultiAgentGraph
Human interaction ApprovalCard, FeedbackBar, RecommendationCard, SelectionToolbar, FineTuneCard
Tools and code ToolChip, ToolCallList, CodeBlock, CodeDiffView, CodeFileTree
Context and sources ContextCard, ContextUsageMeter, CitationChip, SourceChip, AttachmentTile
Models and input ModelPicker, InlineSuggestionBox, VoiceWaveform
Data and insights DiffTable, RecordsTable, FilterTable, SearchPanel, InsightCards, StatTile, ActivityHeatmap, SidebarNav

Requirements

  • Avalonia 12.1.1 or later in the Avalonia 12 release line
  • .NET 8 or later

The controls work with Fluent and Simple base themes and do not depend on a particular model provider or AI SDK.
