Class PromptBar

Namespace
Nova.Avalonia.AIKit.Controls

Nova.Avalonia.AIKit.dll

A message composer with slash commands, attachable sources, a model picker and a dictation toggle. Typing "/" filters CommandsSource and "@" or the attach button lists SourcesSource in a popup above the bar.

[TemplatePart("PART_InputBox", typeof(TextBox))]
[TemplatePart("PART_Popup", typeof(Popup))]
[TemplatePart("PART_EffortButton", typeof(Button))]
[PseudoClasses(new string[] { ":dictating" })]
