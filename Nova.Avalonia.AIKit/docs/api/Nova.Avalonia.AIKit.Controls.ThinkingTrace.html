Remarks

Items can be any object with a matching data template; the built-in theme renders ThinkingStep, ThinkingNote, ThinkingQuery, ThinkingSource and ThinkingToolCall. Supply curated progress summaries and observable actions only; do not expose private chain-of-thought or raw provider reasoning tokens.
