Class SearchPanel

Namespace
Nova.Avalonia.AIKit.Controls
Assembly
Nova.Avalonia.AIKit.dll

A command search card: a search field over a result list that filters live while typing, with an empty state when nothing matches. Selecting a result raises ItemSelected.
