Nova.Avalonia.AIKit

Provider-agnostic Avalonia controls for polished AI-native applications: chat, streaming text, agent activity, approvals, tool calls, code review, retrieval, model selection, and usage dashboards.

Install

dotnet add package Nova.Avalonia.AIKit

Register NovaTheme after the Avalonia base theme:

<Application xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:nova="https://nova-ui.dev/aikit">
  <Application.Styles>
    <FluentTheme />
    <nova:NovaTheme />
  </Application.Styles>
</Application>

Then use the controls directly with MVVM:

<nova:PromptBar Text="{Binding PromptText}"
                ModelsSource="{Binding Models}"
                SelectedModel="{Binding SelectedModel}"
                PlaceholderText="Ask anything…"
                Command="{Binding SubmitPromptCommand}" />

PromptBar.Command receives the trimmed message. Use SubmitCommand for the complete submission snapshot.

AIKit works on top of Fluent or Simple, supports light and dark themes, and has no dependency on a particular model provider or AI SDK.
