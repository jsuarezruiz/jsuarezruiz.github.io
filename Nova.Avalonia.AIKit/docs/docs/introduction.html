Introduction

Nova.Avalonia.AIKit is a UI toolkit for the interaction patterns around an AI system. It deliberately does not send model requests, store conversations, or require a specific provider SDK. Your application owns orchestration and state; AIKit renders that state and turns user actions into commands and routed events.

What the kit provides

  • Conversation controls for prompts, messages, streaming output, citations, and follow-ups.
  • Agent controls for progress, reasoning activity, tool calls, task status, and delegation graphs.
  • Human-in-the-loop controls for approval, recommendations, feedback, and fine-tuning.
  • Code and data controls for diffs, file changes, retrieved context, records, filters, and insights.
  • Shared tokens, accessible light and dark resources, localization strings, and motion policy through NovaTheme.

How state flows

Most controls accept ordinary values or IEnumerable sources. Bind your view model to those properties, then handle a routed event or command when the user acts. This makes the controls suitable for MVVM as well as code-behind samples.

For example, a host can bind its transcript to ChatMessageList.ItemsSource, append chunks to StreamingTextBlock.StreamedText, and handle PromptBar.Submitted to start a model turn. AIKit remains independent of how the host obtains the response.

Platform and theme support

The package targets .NET 8 and Avalonia 12.1.1. Its themes layer on top of Avalonia Fluent or Simple, and the gallery demonstrates desktop, browser, Android, and iOS hosts. Motion-capable controls expose local animation switches and also respect the shared motion policy.

How to use these docs

Start with Getting started, then choose a workflow from the control guide. The Nova.Avalonia.AIKit.Controls API reference contains every property, event, enum, and data item.
