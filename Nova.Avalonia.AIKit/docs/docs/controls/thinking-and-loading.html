Thinking and Loading

Use LoadingIndicator for a compact work state and ThinkingTrace when the host has meaningful steps, notes, searches, sources, or tool activity to disclose.

LoadingIndicator

<nova:LoadingIndicator Text="Churning"
                       Variant="Drive"
                       IsActive="{Binding IsRunning}"
                       ShowElapsedTime="True" />

Choose from Drive, Dots, Orbit, Scan, Signal, and Spark. ElapsedFormat customizes the timer label, while IsAnimationEnabled can disable movement independently of IsActive.

ThinkingTrace

<nova:ThinkingTrace ItemsSource="{Binding Activity}"
                    IsThinking="{Binding IsRunning}"
                    IsExpanded="{Binding IsTraceExpanded}"
                    SummaryText="{Binding ActivitySummary}" />

Populate the source with ThinkingStep, ThinkingNote, ThinkingQuery, ThinkingSource, and ThinkingToolCall items. While IsThinking is true, the header shimmers and elapsed activity is measured. Once complete, SummaryText can replace the active label.

Use ItemsMaxHeight for long traces and bind IsExpanded two-way when expansion belongs in view-model state.
