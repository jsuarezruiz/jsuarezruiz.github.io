Tool Calls

ToolChip displays a single compact status. ToolCallList presents a structured, expandable collection of calls with arguments and output.

<StackPanel Spacing="8">
  <nova:ToolChip Text="Read 4 files" />
  <nova:ToolCallList Header="Agent tools"
                     ItemsSource="{Binding ToolCalls}"
                     IsExpanded="True" />
</StackPanel>

Model tool state

Use ToolCall items with a ToolCallKind, ToolCallStatus, arguments, and optional ToolCallOutput. Output can represent text or a structured form through ToolOutputKind. Update the collection or item state as the orchestrator reports progress.

ToolCallList summarizes one or many calls in its header, supports CallsMaxHeight, and can animate active or newly added work. Set IsAnimationEnabled="False" for static logs or screenshot tests.

ToolChip.IsMonospaced is useful for filenames, commands, and code-oriented labels.
