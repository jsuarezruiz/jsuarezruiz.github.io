Recommendations

RecommendationCard packages a proposed action with its rationale, confidence, alternatives, and stable orchestration metadata. ConfidenceMeter can also be used independently.

<nova:RecommendationCard RecommendationId="restock-waffle-cones"
                         TurnId="{Binding TurnId}"
                         Revision="1"
                         Title="Place this restock order?"
                         Description="Reorder waffle cones from cone_king."
                         Confidence="High"
                         AlternativesSource="{Binding Alternatives}"
                         AcceptCommand="{Binding AcceptRecommendationCommand}"
                         AlternativeSelectedCommand="{Binding ChooseAlternativeCommand}" />

The stable recommendation ID, turn ID, and revision travel with acceptance events, allowing the host to reject stale UI actions safely. IsAccepted and IsAlternativesOpen make the card state bindable. Use RecommendationOption values for alternate actions.

For a standalone semantic indicator:

<nova:ConfidenceMeter Level="Medium"
                      AccessibleName="Recommendation confidence" />

Customize the visible labels with NoneText, LowText, MediumText, and HighText.
