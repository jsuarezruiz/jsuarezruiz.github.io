Common integration pattern

  1. Bind the control's values or ItemsSource to host-owned state.
  2. Update that state as provider or agent events arrive.
  3. Handle routed events or bind commands for user intent.
  4. Send the intent to your application layer; AIKit does not contact a provider itself.

Most collection controls observe INotifyCollectionChanged, so an ObservableCollection<T> is the natural choice for live transcripts, tools, tasks, and timeline events.
