Class RecommendationCard

Namespace
Nova.Avalonia.AIKit.Controls
Assembly
Nova.Avalonia.AIKit.dll

An agent suggestion card: title, description with inline code chips, a confidence meter, an expandable list of alternatives and Accept action. Wrap identifiers in the description in backticks to render them as accent chips.
