Namespace Nova.Avalonia.AIKit.Controls

Classes

ActivityHeatmap

A calendar heatmap: one column per week, one row per weekday, each cell tinted by activity intensity. Values run oldest first, top to bottom within each column. Cells grow to fill the given width, and hovering a cell shows its date and activity.

AgentAvatar

A living avatar for agent presence. The face is a lightweight 3D head: eyes sit on a sphere and follow a yaw/pitch/roll pose that wanders on layered noise, blinks on an organic schedule (sometimes twice), and masks expression changes behind a blink. Moods blend into each other; nothing snaps. Drawn on the render loop with no assets.

AgentLink

A delegation edge between two stable Id values.

AgentNode

One agent in a MultiAgentGraph.

AgentTaskDetail

A label and value pair shown in the expanded part of an AgentTaskRow.

AgentTaskRow

A pill-shaped card that tracks one live agent task: a lifecycle-specific status icon, title, meta text, a status badge and an expandable list of AgentTaskDetail rows.

AgentTimeline

A vertical session history: timestamped entries with kind-colored dots on a connector line, for messages, tool calls, checkpoints, and errors. Observable sources keep the connector correct as entries stream in.

ApprovalAnswerEventArgs

Event arguments for AnswerSubmitted.

ApprovalCard

A human-in-the-loop card that walks through one or more ApprovalQuestions before an agent acts: pick an option or type a custom answer, submit, and step through the questions with the progress footer. Raises Completed once every question is answered and Dismissed when closed.

ApprovalOption

A stable value and user-facing label offered by an ApprovalQuestion.

ApprovalQuestion

A question presented by an ApprovalCard.

AttachmentTile

A file attached to a prompt: a colored type badge, the file name, a detail line and a remove button, with a progress strip along the bottom while uploading.

ChatComposer

A chat input field with a send button. Enter or the button raises Submitted, executes Command with the message text, and can execute SubmitCommand with the structured submission payload.

ChatMessage

A message shown in a ChatMessageList. Messages are display snapshots: replace the item (or reassign the collection) to update one.

ChatMessageList

A scrolling chat transcript of ChatMessage items: user messages as right-aligned bubbles, assistant replies full width with a meta line. Scrolls to the newest message automatically while the viewport remains pinned to the end.

ChatMessageSubmittedEventArgs

Event arguments for Submitted.

CitationChip

A numbered inline citation. Clicking opens a flyout with the source title, domain, and snippet plus a link that opens the source in the browser.

CodeBlock

An agent written code card: a bar with the file name, language and a copy action over numbered, token colored lines. Stream lines by appending CodeLines; include a Caret token to show the writing position.

CodeDiffView

A unified code diff card: a file bar with change stats over gutter numbered lines, where additions tint green and removals tint red with +/− markers.

CodeFileEventArgs

Event arguments for FileSelected.

CodeFileItem

A file or folder display snapshot in a CodeFileTree.

CodeFileTree

A compact list of files the agent touched: indented rows with folder and file icons, change counts, and a status dot. Selecting a file raises FileSelected.

CodeLine

A numbered line in a CodeBlock.

CodeToken

A colored fragment of a CodeLine.

CompanyRecord

A row shown in a RecordsTable. Selection is observable; the other properties are display snapshots set at creation.

ConfidenceMeter

A compact three bar meter that visualizes a ConfidenceLevel: green for high, orange for medium and low, muted when there is no signal.

ContextCard

A retrieved knowledge chunk: a titled card with an excerpt, a meta label such as the character count, and a source pill with a colored file type badge. Set SourceUri to open the source in the browser when clicked.

ContextUsageMeter

A ring gauge for context window consumption. Shows the used share as a sweep with the percentage in the center and a token summary underneath, shifting to warning and critical colors as the window fills.

DiffLine

A line in a CodeDiffView.

DiffTable

A titled three column table that visualizes AI proposed edits: removed rows are tinted red with struck through values, added rows are tinted green.

DiffTableRow

A row shown in a DiffTable.

EffortSelectedEventArgs

Event arguments for EffortSelected.

FeedbackBar

A response action bar: copy, regenerate, and thumbs. A thumb down opens a comment flyout before submitting; after any submission the bar thanks the user.

FeedbackEventArgs

Carries the submitted FeedbackKind and optional comment.

FilterTable

A task table with status filter chips: selecting a chip shows only matching rows. Chips are generated from the distinct Status values with live counts, plus a leading "All" chip.

FilterTableItem

A row shown in a FilterTable. Visibility is animated when filtering.

FilterTableStatus

An immutable status shared by FilterTableItems and shown as a filter chip. Statuses with the same name and color are equal, so separately created instances filter together. To change a row's status, assign a new instance to Status.

FineTuneCard

A design inspector card the agent can drive: a layout switcher, scrubbing numeric fields for size, radius and opacity, and a type dropdown row. While IsAdjusting is true the header shows a shimmering "Adjust" indicator.

FollowUpList

A list of suggested follow-up questions shown under a streamed answer. Selecting an item raises FollowUpSelected and executes Command.

FollowUpSelectedEventArgs

Event arguments for FollowUpSelected.

InlineSuggestionBox

A text input with ghost text completion: the pending suggestion renders dimmed after the caret, Tab accepts it, Escape dismisses it.

Insight

One page of an InsightCards carousel.

InsightCards

A paged carousel of Insights: a header with count and pager arrows over the current insight's narrative, headline stats and trend chart.

InsightSeries

A line drawn by the insight chart.

InsightStat

A headline stat inside an Insight.

LoadingIndicator

A compact loading state composed of an animated pixel grid, a shimmering label and the elapsed time.

ModelEffortOption

A provider-facing reasoning-effort value and its user-facing label.

ModelOption

A model choice shown by a ModelPicker.

ModelPicker

A standalone model dropdown: the trigger shows the current model, the popup lists options with descriptions, metadata, and highlight badges.

ModelSelectedEventArgs

Carries the chosen ModelOption.

MultiAgentGraph

A small network of agents: nodes laid out at relative positions, delegation edges between them, pulses traveling along active edges, and a breathing ring on running nodes. Drawn on the render loop; the loop only runs while something is active.

NovaMotion

Provides the inherited motion policy used by Nova control templates. Applications normally set IsEnabledProperty through the NovaAnimationsEnabled resource.

OperationFailedEventArgs

Reports a recoverable platform operation failure from a control.

PromptBar

RecommendationCard

RecordTag

RecordsTable

SearchPanel

SelectionToolbar

SidebarNav

A workspace sidebar: switcher header, quick search, an accent action row and labeled navigation sections. Clicking an item makes it current and raises ItemSelected.

SourceChip

A compact inline citation pill with an optional icon and monospaced label. Clicking it opens an absolute HTTP or HTTPS Avalonia.Controls.HyperlinkButton.NavigateUri in the default browser; relative and non-web addresses are ignored. Designed to sit inside a StreamingTextBlock but usable anywhere.

StatTile

A compact labeled statistic: a quiet caption above a prominent value, on a field surface. Compose several in a grid for an overview dashboard.

StreamingTextBlock

A text block that reveals appended words with a soft fade, the way chat assistants stream responses. Call AppendText(string) with each new chunk and FlushStreamedText() when the stream ends. Bind StreamedText when the upstream API only exposes growing snapshots. Inline content such as a SourceChip can be added with AppendInline(Control).

ThinkingToolCall

ThinkingTrace

An expandable activity trace for agent work: a sparkle header that shimmers while thinking and collapses to a summary when done, above a timeline of steps, notes, sources or tool calls.

TimelineEntry

VoiceWaveform

Animated dictation level bars. While active the bars dance with a center-weighted envelope scaled by Level; idle they settle into a flat dotted line. Drawn on the render loop.
