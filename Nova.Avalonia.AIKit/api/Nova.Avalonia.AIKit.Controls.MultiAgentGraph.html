Class MultiAgentGraph

Namespace
Nova.Avalonia.AIKit.Controls
Assembly
Nova.Avalonia.AIKit.dll

A small network of agents: nodes laid out at relative positions, delegation edges between them, pulses traveling along active edges, and a breathing ring on running nodes. Drawn on the render loop; the loop only runs while something is active.
