Class ApprovalCard

Namespace
Nova.Avalonia.AIKit.Controls
Assembly
Nova.Avalonia.AIKit.dll

A human-in-the-loop card that walks through one or more ApprovalQuestions before an agent acts: pick an option or type a custom answer, submit, and step through the questions with the progress footer. Raises Completed once every question is answered and Dismissed when closed.

[TemplatePart("PART_OptionsList", typeof(ListBox))]
[TemplatePart("PART_CustomAnswerBox", typeof(TextBox))]
[TemplatePart("PART_DotsPanel", typeof(Panel))]
[PseudoClasses(new string[] { ":completed", ":animations-enabled" })]
