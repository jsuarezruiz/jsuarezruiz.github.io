Weather

Weather lets rain streaks or snowflakes fall across the host's shape in three depths, slanted by the wind. Use it on a weather card, over a photo or a hero section, or for a seasonal touch. Unlike the other fills, it goes over the child by default and draws only the drops, so the content stays visible between them.

  • Light
  • Dark

Add rain

Put the host around the card. The card keeps its own background, and the rain falls over it, clipped to its rounded shape.

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost>
        <fx:FXHost.Layers>
            <fx:Weather />
        </fx:FXHost.Layers>
        <Border Width="340" Height="190" CornerRadius="16" Background="#1E293B" Padding="20">
            <TextBlock Text="Showers until 6 PM" Foreground="White" FontSize="18" FontWeight="SemiBold" />
        </Border>
    </fx:FXHost>
</UserControl>

Styles

Value Description
Rain (default) Thin streaks falling fast.
Snow Soft round flakes drifting slowly down, swaying as they fall.

Snow drifts down slowly, and each flake sways a little as it falls:

<fx:Weather Style="Snow" Density="1.4" Size="1.2" />

Slant it and set the fall

WindAngle slants the fall, in degrees from straight down: positive slants it to the right, negative to the left (12 by default). Density sets how many drops or flakes fall, and Size how big they are, as a multiple (1 is natural). FallSpeed multiplies how fast they fall; at 0 they hold still and the layer asks for no frames.

<fx:Weather WindAngle="-25" Density="2" FallSpeed="1.4" />

To change the pace while it falls, change Speed or FallSpeed; neither makes the animation jump. Fills run on one shared clock, so weather on different hosts, with the same settings from the start, falls in step.

Pick a color for each theme

The default color, a pale blue (#CFE3FF), reads on dark content but all but vanishes on a white card. Give the layer a deeper color in light themes; the gallery uses #5878B0. With theme resources, it changes when the theme does:

<Application.Resources>
    <ResourceDictionary>
        <ResourceDictionary.ThemeDictionaries>
            <ResourceDictionary x:Key="Light">
                <Color x:Key="RainColor">#5878B0</Color>
            </ResourceDictionary>
            <ResourceDictionary x:Key="Dark">
                <Color x:Key="RainColor">#CFE3FF</Color>
            </ResourceDictionary>
        </ResourceDictionary.ThemeDictionaries>
    </ResourceDictionary>
</Application.Resources>

<fx:Weather Color="{DynamicResource RainColor}" />

Fall behind the content

With Placement="Under", the weather falls behind the child instead, like the other fills. Leave the child without a background so the drops show through it, and put any background on a container around the host:

<Border Background="#0F172A" CornerRadius="16">
    <fx:FXHost CornerRadius="16">
        <fx:FXHost.Layers>
            <fx:Weather Style="Snow" Placement="Under" />
        </fx:FXHost.Layers>
        <Grid Height="220">
            <TextBlock Text="Winter sale" Foreground="White" FontSize="28" FontWeight="Bold"
                       HorizontalAlignment="Center" VerticalAlignment="Center" />
        </Grid>
    </fx:FXHost>
</Border>

Properties

Property Type Default Description
Style WeatherStyle Rain What falls: rain streaks or snowflakes. Values: Rain, Snow.
Color Color #CFE3FF The color of the drops or flakes.
Density double 1 How much falls, a multiple of the default. Range 0.1–3.
FallSpeed double 1 How fast it falls, a multiple of the default (0: it hangs still). Range 0–3.
WindAngle double 12 Slant from straight down, degrees: 0 falls straight down; positive slants the fall to the right (counterclockwise), negative to the left. Range -60 to 60.
Size double 1 Size of the drops or flakes, a multiple: 1 is natural. Range 0.3–4.
BorderWidth double 0 Width of a band inside the edge, DIPs. 0: the whole shape. Range 0–48.
UseMask bool false Paints only the child's own pixels (text, icons, a logo) instead of the shape: gradient text, a liquid-metal logo, holographic icons. It then goes over the child unless Placement says otherwise. The host captures the child to know its pixels: call RefreshMask after changing something deep inside it.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. On a fill, Intensity is its coverage, up to 1.

Notes

  • Light and dark surfaces: the drops are drawn in Color on any surface, so pick a color for each theme, as above. See Light and dark surfaces.
  • Reduced motion: the rain or snow holds one fixed pose. See Reduced motion.
  • Cost: about 0.07 ms of GPU time a frame on the benchmark's 340×190 card. The cost grows with the area. See Performance.
  • Room: the drops are clipped to the host's shape. Rain needs some height to read as rain, so it suits a card or a panel more than a button.
  • Bands and masks: like every fill, it has BorderWidth, which paints only a band inside the edge, and UseMask, which lets it fall only on the child's own pixels, such as large text. See Content masks.
