Color filter

ColorFilter recolors what is drawn within the host's shape, live: grayscale, sepia, saturation, hue, brightness and contrast with CSS's own formulas, plus temperature, tint, duotone and invert. Use it for a disabled state, a photo that stays gray until hovered, a styled thumbnail or a picture dimmed in a dark theme. It reads what is already drawn rather than a snapshot of the child, so it keeps up with whatever the child does. Where it draws decides what it recolors.

  • Light
  • Dark

Add a color filter

Wrap the content in a host. The filter starts as grayscale, so it shows something with no settings:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost>
        <fx:FXHost.Layers>
            <fx:ColorFilter />
        </fx:FXHost.Layers>
        <Image Source="/Assets/photo.jpg" Width="240" Height="140" Stretch="UniformToFill" />
    </fx:FXHost>
</UserControl>

Presets

A preset sets several settings at once. It applies at template priority, so a local value on any setting wins over it. None puts every setting at rest, to start from the picture as it is.

Value Description
Grayscale (default) Fully gray: the colors drained, the lightness kept.
Sepia Toned brown, like an old photograph.
Vivid More saturated, a little more contrast.
Faded Washed out and lifted, like an old print.
Warm A warmer white balance: redder, less blue, a little more saturated.
Cool A cooler white balance: bluer, less red.
Duotone Lightness mapped from a deep violet to a warm cream.
Invert A negative: every color inverted.
None Every setting at rest: the picture as it is.

Choose what it recolors

The layer works on what is drawn within the shape just before it draws (see Layers that read the backdrop). Its placement decides what that is:

To recolor Set Like CSS
The child and anything that shows through it Nothing: by default it draws over the child filter
Only what is behind the host, with the child unchanged on top Placement="Under" backdrop-filter
Only the child's own pixels: an icon, not the card around it UseMask="True"

Under the child, the filter needs something drawn behind the host, such as a picture, a list or the page's background, and the child should be see-through where the filtered backdrop is meant to show. Here a caption bar fades the photo behind it:

<Grid>
    <Image Source="/Assets/photo.jpg" Stretch="UniformToFill" />
    <fx:FXHost VerticalAlignment="Bottom">
        <fx:FXHost.Layers>
            <fx:ColorFilter Placement="Under" Preset="Faded" Brightness="0.7" />
        </fx:FXHost.Layers>
        <Border Height="56" Padding="16,0">
            <TextBlock Text="Lisbon, 2019" Foreground="White" VerticalAlignment="Center" />
        </Border>
    </fx:FXHost>
</Grid>

With UseMask, the host captures the child to learn its pixels (see Content masks), and only those pixels change:

<fx:FXHost>
    <fx:FXHost.Layers>
        <fx:ColorFilter UseMask="True" Preset="Duotone" />
    </fx:FXHost.Layers>
    <Image Source="/Assets/logo.png" Width="64" />
</fx:FXHost>

Keep it gray until hover

Intensity is how much of the filter shows. Fade it out while the pointer is over a host with Classes="photo":

<Style Selector="fx|FXHost.photo fx|ColorFilter">
    <Setter Property="Transitions">
        <Transitions>
            <DoubleTransition Property="Intensity" Duration="0:0:0.3" />
        </Transitions>
    </Setter>
</Style>
<Style Selector="fx|FXHost.photo:pointerover fx|ColorFilter">
    <Setter Property="Intensity" Value="0" />
</Style>

Mix your own

Start from Preset="None" and set only what you need. Tint tones the picture toward a color at the same lightness, and its alpha is how much; Duotone maps lightness from ShadowColor to HighlightColor:

<fx:ColorFilter Preset="None" Saturation="1.3" Contrast="1.1" Hue="-15" Tint="#40FF8A00" />

Properties

Property Type Default Description
Preset ColorFilterPreset Grayscale A set of the settings below. The default is Grayscale; None puts every setting at rest, to start from the picture as it is (a local value on any setting wins over the preset). Values: Grayscale, Sepia, Vivid, Faded, Warm, Cool, Duotone, Invert, None.
Grayscale double 1 How far the colors drain to gray: 0 none, 1 fully gray (CSS grayscale()). Range 0–1 (0–100%).
Sepia double 0 How far the picture tones to brown, like an old photograph: 0 none, 1 full (CSS sepia()). Range 0–1 (0–100%).
Saturation double 1 1: as it is; 0: gray; above 1: more vivid. Range 0–3.
Hue double 0 Turns every hue around the color wheel, degrees: 0 leaves them; positive turns red toward yellow and green, as CSS's hue-rotate does. Range -180 to 180.
Brightness double 1 1: as it is; 0: black. Range 0–3.
Contrast double 1 1: as it is; 0: flat gray. Range 0–3.
Temperature double 0 Warmer (positive) or cooler (negative) white balance. Range -1 to 1.
Tint Color #00FFFFFF A color the picture is toned toward at the same lightness; its alpha is how much.
Duotone double 0 How much the picture becomes two colors, its lightness running from ShadowColor to HighlightColor. Range 0–1 (0–100%).
ShadowColor Color #2B1055 The duotone color for the darkest parts; applies as Duotone rises.
HighlightColor Color #FFD3A0 The duotone color for the lightest parts; applies as Duotone rises.
Invert double 0 How far the colors invert: 0 none, 1 a negative; 0.5 is flat gray (CSS invert()). Range 0–1 (0–100%).
UseMask bool false Recolors only the child's own pixels (text, an icon, a picture), not the shape around them.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. The filter is still, so Speed and Seed don't apply.

Notes

  • Light and dark surfaces: it draws the same on both. To dim pictures in a dark theme only, give Brightness a value per theme with a theme resource, as Light and dark surfaces does for colors.
  • Reduced motion: nothing moves, so nothing changes.
  • Cost: it doesn't animate, so it only redraws when what it reads changes. On the benchmark card it takes about 0.11 ms of GPU time a frame. With every setting at rest it copies nothing and draws nothing. See Performance.
  • Keep ancestors opaque. Inside an offscreen layer (an ancestor with Opacity below 1, an effect, or a clip that needs a layer) the copy can't see that ancestor's content. A disabled style that lowers a parent's Opacity is a common case: dim with the filter's own Brightness instead.
  • With UseMask, the host watches only the child itself. After changing something deeper inside it, call RefreshMask.
