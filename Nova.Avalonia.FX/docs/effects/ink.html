Ink

Ink fills the host's shape with colored fluid that answers the pointer. Moving the pointer pushes the fluid and leaves ink in a color that changes as it goes; a press throws a pinwheel splash of every color; and the ink swirls, spreads and fades. Use it on a hero, a playful empty state or a drawing surface. It draws over the child, inside the shape, and runs a small fluid simulation only while there is ink to show.

  • Light
  • Dark

Add ink

Put an Ink layer on a panel. It needs room to stir, so it suits a card or a larger surface better than a button.

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost CornerRadius="12">
        <fx:FXHost.Layers>
            <fx:Ink />
        </fx:FXHost.Layers>
        <Border Width="320" Height="220" CornerRadius="12" Background="#0B0C12" Cursor="Hand">
            <TextBlock Text="Move or press" Foreground="#8B90A0" FontSize="12"
                       HorizontalAlignment="Center" VerticalAlignment="Bottom" Margin="0,0,0,8" />
        </Border>
    </fx:FXHost>
</UserControl>

Unset, the ink cycles through a bright set of five colors. Colors takes your own list, separated by commas:

<fx:Ink Colors="#F43F5E, #F59E0B, #10B981" />

Tune the fluid

Life is about how long the ink lasts before it has faded. SplatSize sets how wide each drop is, and Swirl how much the fluid curls into eddies. CellSize is the simulation's cell: smaller is finer and costs more.

<fx:Ink Life="5" SplatSize="40" Swirl="2" />

Splash from code

A press on the host throws a splash where it lands, because SplashOnPress is on by default; the press has to land on the host's content, so give it a background. Splash() throws one from code, at a point in the host's coordinates or at the center. PointAt stirs the fluid as if the pointer were there; null lifts it.

// InkLayer is the Ink layer.
private void OnMessageArrived(object? sender, EventArgs e)
{
    InkLayer.Splash();
}

Methods

Method Description
Splash(Point? at = null) Throws a splash of every color at at (host coordinates), or the center.
PointAt(Point? at) Moves the ink's pointer to at (host coordinates), stirring the fluid along the way; null lifts it.

Properties

Property Type Default Description
Colors FXColorList Unset The colors the ink cycles through; unset, a bright set of five.
Life double 2.5 About how long the ink lasts before it has faded. Range 0.3–10 seconds.
SplatSize double 26 How wide each drop of ink is. Range 4–120 DIPs.
Swirl double 1.2 How much the fluid curls into eddies. Range 0–3.
CellSize double 6 Simulation cell size: smaller is finer and costs more. Range 3–16 DIPs.
SplashOnPress bool true Throws a splash where the host is pressed.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. On ink, Intensity dims the layer and Seed doesn't apply.

Notes

  • Light and dark surfaces. On a dark surface the ink glows as added light. On a light surface it draws as tinted haze. See Light and dark surfaces.
  • Reduced motion. The ink stays where it lands and fades. See Reduced motion.
  • Cost. The simulation steps on the render thread only while there is ink; once it has faded, the grid clears and the layer draws nothing and costs nothing. While ink moves, about 0.02 ms of GPU time a frame on the bench's 340×190 card. See Performance.
  • The pointer. The pointer stirs the ink while it is over the shape. See Layers that follow the pointer.
  • Small targets. The ink covers the child while it swirls, so on a button or a field it hides the label.
