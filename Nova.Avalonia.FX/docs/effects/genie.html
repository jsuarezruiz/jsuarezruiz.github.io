Genie

Genie hides the host's content by pulling it into a point, like a window minimizing into the dock, and pours it back out to show it. The sides bend in toward the point first, then the content slides down the funnel into it. Use it to send a panel to a dock icon, a file to the trash or a note into a folder. Like Reveal, it captures the content, hides the real element while it plays, and hands it back once shown.

  • Light
  • Dark

Add a genie

Set Target to the control the content goes into, and bind IsShown. Here the dock icon minimizes the note and brings it back:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <Grid RowDefinitions="*,Auto">
        <fx:FXHost CornerRadius="12" ZIndex="1" HorizontalAlignment="Center" VerticalAlignment="Center">
            <fx:FXHost.Layers>
                <fx:Genie Target="{Binding #DockIcon}" IsShown="{Binding #DockIcon.IsChecked}" />
            </fx:FXHost.Layers>
            <Border Width="176" Height="100" CornerRadius="12" Padding="12" Background="#15171c">
                <TextBlock Text="Notes" Foreground="White" FontWeight="SemiBold" />
            </Border>
        </fx:FXHost>
        <ToggleButton x:Name="DockIcon" Grid.Row="1" IsChecked="True" Width="32" Height="32"
                      HorizontalAlignment="Center" Margin="0,0,0,10" />
    </Grid>
</UserControl>

The funnel draws outside the host on its way to the point. ZIndex="1" keeps the dock row, a later sibling, from covering it.

Pull it into a control or a point

The content goes into, and pours out of, one point:

  • the point given to Hide(toward) or Show(from), in the host's coordinates;
  • otherwise the center of Target, a control anywhere in the same window, such as a dock icon or a trash button;
  • otherwise the bottom center of the content.

With a Target, the funnel's neck is most of the target's width; without one it narrows to a small neck. For wide, short content, use a point well below it, so the funnel has room to bend. Genie works best on a card or a panel; bare text breaks into spikes.

Show and hide from code

IsShown is true by default and binds both ways, so Show() and Hide() also update a bound view-model property. Set IsShown="False" in XAML to start hidden, with no transition.

private void OnDelete(object? sender, RoutedEventArgs e)
{
    // Pull the card into the middle of the trash button.
    var center = new Point(TrashButton.Bounds.Width / 2, TrashButton.Bounds.Height / 2);
    CardGenie.Hide(TrashButton.TranslatePoint(center, CardHost));
}

private void OnRestore(object? sender, RoutedEventArgs e) => CardGenie.Show();

From a view model, bind IsShown to a property, such as IsNoteOpen, and set it to false to minimize the note. While hidden, the element is transparent but keeps its place in the layout, and it still takes clicks and keyboard focus.

Duration is the length of one transition in seconds (0.6 by default); the layer's Speed doesn't apply, and a change applies from the next transition. With nothing to capture (no child, a child that isn't visible or isn't laid out yet, or IsActive off) the layer switches at once. To play it as a view opens, start hidden and call Show() from the view's Loaded event. Reveal shows the pattern.

Methods

Show and Hide play the transition from code, from or toward a point.

Method Description
Show(Point? from = null) Shows the content, playing the layer's transition from from (host coordinates). Null: the layer's own point.
Hide(Point? toward = null) Hides the content, playing the layer's transition toward toward (host coordinates). Null: the layer's own point.

Properties

Property Type Default Description
IsShown bool true Whether the content is shown. Setting it false pulls the content into the point; true pours it back out.
Duration double 0.6 How long the transition takes, in seconds. Range 0.15–3.

Target (Control, unset by default) is the element the content goes into, by its center, when no point is given.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. Genie has no randomness, so Seed does nothing.

Notes

  • Light and dark. Genie draws the same on both surfaces: it shows the content as captured.
  • Reduced motion. It becomes a fade of at most a quarter of a second. See the poses.
  • Cost. Under 0.05 ms of GPU time a frame on a card while it plays, plus rendering the content once into an image when it starts. Otherwise it draws nothing. See What a layer costs.
  • Clipping. The funnel reaches from the content to the point, outside the host, so a clipping ancestor between them cuts it: a ScrollViewer, or a Border with ClipToBounds.
