Grain

Fine film grain inside the shape: specks a little lighter and a little darker than what is beneath them, one device pixel each. It adds texture to gradients, pictures and flat fills, and breaks up banding in soft color ramps. It draws over the host's child, and it is static by default, so it never shimmers and costs nothing after its first frame.

  • Light
  • Dark

Add grain

Put a Grain over a card with a picture or a gradient:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost>
        <fx:FXHost.Layers>
            <fx:Grain Amount="0.09" />
        </fx:FXHost.Layers>
        <Border Width="340" Height="190" CornerRadius="16">
            <Border.Background>
                <LinearGradientBrush StartPoint="0%,0%" EndPoint="100%,100%">
                    <GradientStop Color="#7C3AED" Offset="0" />
                    <GradientStop Color="#EC4899" Offset="0.55" />
                    <GradientStop Color="#F59E0B" Offset="1" />
                </LinearGradientBrush>
            </Border.Background>
        </Border>
    </fx:FXHost>
</UserControl>

The default Amount of 0.03 is subtle on purpose. Raise it for a stronger, more visible texture.

Add grain to a fill

Grain goes over the child and fills go under it, so a fill and a grain in the same host sandwich the content. This gives a mesh gradient a printed, analog look:

<fx:FXHost>
    <fx:FXHost.Layers>
        <fx:MeshGradient Preset="Dusk" />
        <fx:Grain Amount="0.05" />
    </fx:FXHost.Layers>
    <Border Width="260" Height="116" CornerRadius="16" Padding="16">
        <TextBlock Text="Dusk" FontSize="19" FontWeight="Bold" Foreground="White"
                   VerticalAlignment="Bottom" />
    </Border>
</fx:FXHost>

Animate the grain

Fps draws new grain that many times a second, like film running through a projector. At 0 (the default) the grain holds still:

<fx:Grain Amount="0.08" Fps="24" />

Feather fades the grain in from the shape's edge, in DIPs.

Properties

Property Type Default Description
Amount double 0.03 How strong the grain is: how far each pixel is lightened or darkened. Range 0–0.3 (0–30%).
Fps double 0 New grain per second. 0: static. Range 0–60.
Feather double 0 How far inside the shape's edge the grain fades in, in DIPs (0: a crisp edge). Range 0–24.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale.

Notes

  • Intensity multiplies Amount, up to 3. Seed picks a different grain pattern.
  • Light and dark surfaces: grain draws the same on both. It reads best over a picture or a gradient; on a plain white card it all but vanishes.
  • Reduced motion: animated grain holds still. See Reduced motion.
  • Cost: among the cheapest layers, 0.019 ms of GPU time per frame on a 340×190 card in the gallery's bench, and nothing at all while static. Leave RenderScale at 1: the scale-up pass made grain slower (from about 0.07 ms to 0.10–0.19 ms on a 700×500 panel) and would soften it. See Render scale.
