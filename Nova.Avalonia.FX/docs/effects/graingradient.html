Grain gradient

A gradient with a printed, risograph feel: film grain scatters each point along the color ramp, so neighboring colors stipple into each other instead of blending flat, and a little brightness grain rides on top. It runs in a line, outward from a center, or around one (conic). Use it for buttons, avatars, cover art and posters. It is a fill: it paints the host's shape and goes under the child, or paints the child's own pixels with UseMask.

  • Light
  • Dark

Add a grain gradient

The fill goes under the child, so leave the child without a background:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost>
        <fx:FXHost.Layers>
            <fx:GrainGradient Preset="Ember" />
        </fx:FXHost.Layers>
        <Border Width="220" Height="56" CornerRadius="14">
            <TextBlock Text="Generate" Foreground="White" FontWeight="Bold"
                       HorizontalAlignment="Center" VerticalAlignment="Center" />
        </Border>
    </fx:FXHost>
</UserControl>

Presets and kinds

Each preset brings a palette and sets Kind, Angle, Center and IsMonochrome: Ember is linear, Halo radial and Sweep conic, in color grain. Set any of them yourself to adjust a preset.

Preset

Value Description
Ember (default) A linear glow from deep plum through crimson and orange to pale gold.
Halo A radial glow, pale blue-white above the middle, darkening through blue to near-black navy.
Sweep A conic sweep from the top through teal, blue, violet, pink and amber, with color grain.

Kind

Value Description
Linear (default) The colors run in a straight line across the shape, along the angle.
Radial The colors run out from Center in rings.
Conic Sweeps around Center, starting at the angle; loops.

Pick the kind of gradient

The colors in Colors run along the ramp in order, up to six:

  • Linear runs across the shape along Angle: 0 is left to right, and positive angles turn clockwise.
  • Radial starts at Center with the first color and runs outward.
  • Conic sweeps clockwise around Center, starting at Angle (0 points right), and loops back to the first color, so there is no seam.

Center is a point in fractions of the shape, from 0,0 (top left) to 1,1:

<StackPanel Orientation="Horizontal" Spacing="14">
    <fx:FXHost CornerRadius="999">
        <fx:FXHost.Layers>
            <fx:GrainGradient Kind="Radial" Center="0.5,0.35" Colors="#E9F1FF, #7AA2FF, #2A2F7A, #0B0D1F" />
        </fx:FXHost.Layers>
        <Border Width="80" Height="80" />
    </fx:FXHost>
    <fx:FXHost CornerRadius="999">
        <fx:FXHost.Layers>
            <fx:GrainGradient Kind="Conic" Angle="-90" Colors="#00C2A8, #3A86FF, #8338EC, #FF006E" />
        </fx:FXHost.Layers>
        <Border Width="80" Height="80" />
    </fx:FXHost>
</StackPanel>

Tune the grain

Amount sets how far the grain scatters the colors and their brightness; at 0 the gradient is smooth. GrainSize is the size of one grain in DIPs. IsMonochrome uses one grain value for all channels; turn it off for color grain. Fps is how many times a second the grain re-rolls, 12 by default; at 0 it holds still:

<fx:GrainGradient Preset="Halo" Amount="0.7" GrainSize="1.5" Fps="0" />

Properties

Property Type Default Description
Preset GrainGradientPreset Ember A ready-made look: the palette used while Colors is unset, with its Kind, Angle, Center and IsMonochrome. Local values win. Values: Ember, Halo, Sweep.
Colors FXColorList Unset The colors (up to six). Unset: the preset's palette.
Kind GradientKind Linear The gradient's shape: linear, radial from Center, or conic around it. Values: Linear, Radial, Conic.
Angle double 69 Linear: the way the colors run (0: left to right). Conic: where the sweep starts (0: to the right); it sweeps clockwise. Degrees; positive turns clockwise. Range -180 to 180. Applies to the Linear and Conic kinds.
Center Point 0.5,0.5 Radial and conic center, 0..1 across the rect. Applies to the Radial and Conic kinds.
Amount double 0.4 How far grain scatters the gradient and its brightness. Range 0–1 (0–100%).
GrainSize double 0.5 Size of a grain, in DIPs. Range 0.5–8.
IsMonochrome bool true One grain value for all channels; off gives color grain.
Fps double 12 Grain re-rolls per second (0: static). Range 0–30.
BorderWidth double 0 Width of a band inside the edge, DIPs. 0: the whole shape. Range 0–48.
UseMask bool false Paints only the child's own pixels (text, icons, a logo) instead of the shape: gradient text, a liquid-metal logo, holographic icons. It then goes over the child unless Placement says otherwise. The host captures the child to know its pixels: call RefreshMask after changing something deep inside it.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale.

Notes

  • Intensity is the fill's coverage, from 0 to 1. Seed picks a different grain pattern.
  • Idle: with Fps or Amount at 0, the gradient holds still and requests no frames.
  • Light and dark surfaces: the gradient draws the same on both. On gradient text, pick colors that stand out from the background behind the text.
  • Reduced motion: the grain holds still. See Reduced motion.
  • Cost: 0.073 ms of GPU time per frame on a 340×190 card in the gallery's bench. Leave RenderScale at 1: it would soften the grain.
  • Like every fill, it can paint only the child's own pixels with UseMask, or a band inside the edge with BorderWidth.
