Electric

Electric draws lightning: a jagged bolt that strikes with a flash, holds, and re-strikes, mostly down the same channel, while earlier strikes linger as afterimages and forks shoot out and cool. It can crawl around the host's border, jump between two points of the shape, or run as a calm charged hairline. Use it for an overcharged or boosted state, a connection between two nodes, or a zap when something is pressed. It draws over the child.

  • Light
  • Dark

Add lightning

The default style, Border, runs lightning around the shape just outside its edge.

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost>
        <fx:FXHost.Layers>
            <fx:Electric Style="Border" Color="#4F8DFF" />
        </fx:FXHost.Layers>
        <Border Width="210" Height="50" CornerRadius="12" Background="#15171C">
            <TextBlock Text="Overcharged" Foreground="White" FontWeight="SemiBold"
                       HorizontalAlignment="Center" VerticalAlignment="Center" />
        </Border>
    </fx:FXHost>
</UserControl>

Amplitude sets how far the bolt strays sideways, JagDensity how jagged it is, and StrikeRate how often it re-strikes. Gap moves a border bolt further out from the edge, or inside it with a negative value.

Styles

Value Description
Border (default) Lightning crawling around the border.
Arc Lightning between two points of the shape (From, To).
Charged A calm, continuously crawling hairline with beads of charge: the UI variant.

Charged sets a calmer set of values for the bolt (amplitude, density, strike rate, widths, forks, flicker, strands, gap, fork length and intensity) at template priority. Set any of them yourself to override it.

<fx:Electric Style="Charged" Color="#7C5CFF" />

Lightning between two points

With Style="Arc", the bolt runs from From to To, given as fractions of the shape: 0,0 is the top left, 1,1 the bottom right. Put the nodes it connects inside the host.

<fx:FXHost>
    <fx:FXHost.Layers>
        <fx:Electric Style="Arc" From="0.1,0.5" To="0.9,0.5" Amplitude="6" />
    </fx:FXHost.Layers>
    <Grid Width="230" Height="34">
        <Ellipse Width="12" Height="12" Fill="#4F8DFF" HorizontalAlignment="Left" Margin="17,0,0,0" />
        <Ellipse Width="12" Height="12" Fill="#4F8DFF" HorizontalAlignment="Right" Margin="0,0,17,0" />
    </Grid>
</fx:FXHost>

Zap on a press

Zap() fires a single strike: a flash, usually a re-strike, then an afterimage that fades. Set ZapOnPress to zap whenever the host is pressed, and turn IsContinuous off so the bolt only shows during a zap. On an arc, a zap at a point strikes from the nearer node to that point.

<fx:FXHost>
    <fx:FXHost.Layers>
        <fx:Electric IsContinuous="False" ZapOnPress="True" Color="#A78BFA" CoolColor="#EC4899" />
    </fx:FXHost.Layers>
    <Button Content="Zap me" />
</fx:FXHost>

From code, call Zap() on the named layer for a strike along the style's own path, or pass a point in the host's coordinates:

private void OnArcReleased(object? sender, PointerReleasedEventArgs e)
{
    // ArcBolt is the Electric layer, ArcHost its FXHost.
    ArcBolt.Zap(e.GetPosition(ArcHost));
}

Methods

Method Description
Zap(Point? at = null) One strike: a flash, usually a re-strike down the same channel, then the afterimage fades (0.5 s). On an arc, at (host coordinates) makes the strike jump from the nearer node to that point instead of between the nodes.

Properties

Property Type Default Description
Style ElectricStyle Border Where the lightning runs: around the border, between two points, or a calm charged hairline. Choosing a style resets the bolt settings to its defaults (local values win). Values: Border, Arc, Charged.
Color Color #4F8DFF The glow's color around the bolt; forks pass through it as they cool.
CoreColor Color #EAF3FF The white-hot core of the channel.
CoolColor Color #7A4DFF The color forks cool to.
Amplitude double 5 How far the bolt strays sideways. Range 0–24 DIPs.
JagDensity double 2.4 How jagged the bolt is: jags per 100 DIPs. Range 0.5–8.
StrikeRate double 3.2 How often it re-strikes: about 0.55 / rate seconds between strikes. Range 0–10 per second.
CoreWidth double 0.6 Width of the bolt's bright core, in DIPs. Range 0.2–3.
GlowRadius double 5 How far the glow spreads around the bolt, in DIPs. Range 0.5–16.
Forks double 0.55 Chance of forks at each strike. Range 0–1 (0–100%).
Flicker double 0.45 How much the bolt's brightness wavers, and how bright its return strokes are (0: steady). Range 0–1 (0–100%). Applies to the Arc and Border styles.
Strands int 2 The live strike plus up to two afterimages. Range 1–3. Applies to the Arc and Border styles.
Gap double 2 How far outside the edge a border bolt runs. Range -8 to 16 DIPs. Applies to the Border and Charged styles.
ForkLength double 20 Length of the forks that shoot off the bolt, in DIPs. Range 0–80. Applies to the Border and Charged styles.
Occlusion double 0.12 How much the glow also covers what is behind it. Range 0–1 (0–100%).
From Point 0,0.5 Arc start, as a fraction of the shape's rect (0,0 top left; 1,1 bottom right). Applies to the Arc style.
To Point 1,0.5 Arc end, as a fraction of the shape's rect. Applies to the Arc style.
IsContinuous bool true Strike continuously. Off: draw only during a Zap.
ZapOnPress bool false Zaps whenever the pointer is pressed on the host.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. On lightning, Intensity is the strength of the light, up to 3.

Notes

  • Light and dark surfaces. On a dark surface the bolt adds light with a white-hot core. On a light surface its core becomes a crisp line in a deep shade of Color over a pale tint of its glow. See Light and dark surfaces.
  • Reduced motion. The continuous bolt holds one shape; a zap still strikes. See Reduced motion.
  • One-shots. With IsContinuous off, the layer draws nothing between zaps. Zaps overlap; when too many are live, the oldest fades out. See One-shots.
  • Cost. About 0.08 ms of GPU time a frame on the bench's 340×190 card. Electric builds its bolt paths on the CPU, so it takes more CPU time than most layers: about 0.06 ms a frame on the desktop. In the browser that work takes 0.45–0.6 ms a frame when interpreted and 0.12–0.3 ms when compiled ahead of time; compile ahead of time if the app leans on lightning and must run well on slower machines. See Performance.
  • Room around the host. Bolts, glow and forks reach past the shape. A clipping ancestor cuts them off: leave room around the host. The border styles shade only a ring around the edge, not the interior.
