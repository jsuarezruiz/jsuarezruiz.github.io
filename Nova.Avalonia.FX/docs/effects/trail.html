Trail

Trail leaves a mark behind the pointer as it moves over the host: a glowing ribbon that tapers and fades, or a stream of sparks that drift, twinkle and fall. It runs from the head color at the pointer to the tail color at the end. Use it on a playful hero, a game screen or a drawing surface. It draws over the child, and a still pointer leaves nothing.

  • Light
  • Dark

Add a trail

Put a Trail on the panel the pointer moves over. Width sets the ribbon's thickness and Life how long each point of the trail lasts.

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost CornerRadius="12">
        <fx:FXHost.Layers>
            <fx:Trail Color="#A78BFA" TailColor="#22D3EE" Width="6" Life="0.45" />
        </fx:FXHost.Layers>
        <Border Width="340" Height="220" CornerRadius="12" Background="#15171C" />
    </fx:FXHost>
</UserControl>

Glow scales the soft light around the ribbon; 0 leaves a plain stroke.

Styles

Value Description
Ribbon (default) A glowing ribbon that tapers and fades behind the pointer.
Sparkles Sparks shed along the path that drift, twinkle and fall. 
<fx:FXHost CornerRadius="10">
    <fx:FXHost.Layers>
        <fx:Starfield Density="0.6" Twinkle="0.4" Speed="0.3" />
        <fx:Trail Style="Sparkles" Color="#FFE08A" TailColor="#FF8FD8" Width="5" Life="0.7" />
    </fx:FXHost.Layers>
    <Grid Width="340" Height="220">
        <TextBlock Text="Move the pointer here" Foreground="#C9D2FF"
                   HorizontalAlignment="Center" VerticalAlignment="Center" />
    </Grid>
</fx:FXHost>

Keep the trail going past the edge

By default the pointer only leaves a trail while it is over the shape. PointerReach extends that some DIPs past the edge, so a trail doesn't stop abruptly where the shape ends.

<fx:Trail PointerReach="40" />

Draw a trail from code

PointAt moves the trail's head as if the pointer were there, adding a point each time; null lifts it and the trail fades. Use it for a demo or an onboarding hint. The pointer takes over again when it moves.

// DemoTrail is the Trail layer. Sweeps a wave across the panel, then lifts.
var start = DateTime.Now;
DispatcherTimer.Run(() =>
{
    var t = (DateTime.Now - start).TotalSeconds;
    if (t > 1.2) { DemoTrail.PointAt(null); return false; }
    DemoTrail.PointAt(new Point(20 + t * 240, 110 + Math.Sin(t * 6) * 40));
    return true;
}, TimeSpan.FromMilliseconds(16));

Methods

Method Description
PointAt(Point? at) Moves the trail's head to at (host coordinates), as if the pointer were there, adding a point to the trail; null lifts it and the trail fades.

Properties

Property Type Default Description
Style TrailStyle Ribbon What follows the pointer: a glowing ribbon, or a stream of sparks. Values: Ribbon, Sparkles.
Color Color #A78BFA The ribbon's color at its head; each spark takes a mix of this and TailColor.
TailColor Color #22D3EE The color the ribbon fades to at its tail.
Width double 6 Width of the ribbon at its head, in DIPs (it tapers behind); for sparks, their size. Range 1–30.
Life double 0.45 How long a point of the trail lasts. Range 0.1–2 seconds.
Glow double 0.8 The soft light around the ribbon, a multiple: 1 is full, 0 none. Range 0–2. Applies to the Ribbon style.
PointerReach double 0 How far outside the shape the pointer still leaves a trail. Range 0–200 DIPs.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. On a trail, Intensity dims the layer and Seed doesn't apply.

Notes

  • Light and dark surfaces. On a dark surface the trail adds light. On a light surface it draws as tinted haze in its own colors. See Light and dark surfaces.
  • Reduced motion. There is no trail: it only exists as motion. See Reduced motion.
  • Cost. Nothing while the pointer is still or away. While it moves, about 0.17 ms of GPU time a frame on the bench's 340×190 card. The trail keeps the pointer's last 32 positions. See Performance.
  • The pointer. The host listens to the window's pointer while the layer is active and passes it on within the shape plus PointerReach. See Layers that follow the pointer.
  • Room around the host. Sparks fall and the glow spreads a little past the shape. A clipping ancestor cuts them off.
