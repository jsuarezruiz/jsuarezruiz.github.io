Magnifier

Magnifier is a glass loupe that follows the pointer over the host and magnifies what is under it, with a rim, a soft shadow and a slight color split toward its edge. Use it for fine print, charts, maps and product photos. It grows in when the pointer arrives and fades when it leaves, and PointAt aims it from code. It draws over the child and magnifies what is drawn there: the child and anything behind it that shows through.

  • Light
  • Dark

Add a magnifier

Wrap the content to magnify in a host:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost>
        <fx:FXHost.Layers>
            <fx:Magnifier Radius="48" Zoom="2" />
        </fx:FXHost.Layers>
        <Image Source="/Assets/map.png" Width="480" />
    </fx:FXHost>
</UserControl>

Choose what it covers

  • It follows the pointer only over the host's shape. To magnify a whole panel, wrap the panel, not one item in it.
  • It magnifies what is drawn before it. It copies what is under the lens just before it draws (see Layers that read the backdrop): the child, and whatever shows through the child's see-through parts. Controls drawn after the host sit in front of the lens and aren't magnified.
  • The lens can reach past the shape when the pointer is near an edge. A clipping ancestor cuts it there.
  • Keep ancestors opaque. Inside an offscreen layer (an ancestor with Opacity below 1, an effect, or a clip that needs a layer) the copy can't see that ancestor's content.

Aim it from code

PointAt(at) holds the lens over a point in the host's coordinates, as if the pointer were there: for keyboard focus or a guided tour. PointAt(null) puts it away, and the pointer takes over again when it moves. This holds the lens over a label while it has keyboard focus:

PriceLabel.GotFocus += (_, _) =>
{
    var center = new Point(PriceLabel.Bounds.Width / 2, PriceLabel.Bounds.Height / 2);
    ChartLoupe.PointAt(PriceLabel.TranslatePoint(center, ChartHost));
};
PriceLabel.LostFocus += (_, _) => ChartLoupe.PointAt(null);

Size the lens

Radius sets the lens's size and Zoom how much it magnifies. FollowTime is how long it takes to catch up with the pointer; 0 sticks to it. Rim, Shadow and Dispersion shape the glass:

<fx:Magnifier Radius="80" Zoom="2.5" FollowTime="0.1" Dispersion="0" />

Methods

Call PointAt to aim the lens without a pointer.

Method Description
PointAt(Point? at) Holds the lens over at (host coordinates); null puts it away.

Properties

Property Type Default Description
Radius double 56 Radius of the lens, in DIPs. Range 12–200.
Zoom double 1.8 How much the lens magnifies at its center: 1 not at all, 2 twice the size. Range 1–5.
Rim double 1 Strength of the light on the lens's rim (0: none). Range 0–2.
Shadow double 0.45 How dark the soft shadow around the lens is (0: none). Range 0–1 (0–100%).
Dispersion double 0.2 Color split toward the rim. Range 0–1 (0–100%).
FollowTime double 0.04 How long the lens takes to catch up with the pointer (a time constant). Range 0–0.5 seconds.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. The lens follows the pointer, not a clock, so Speed and Seed don't apply.

Notes

  • Light and dark surfaces: it draws the same on both.
  • Reduced motion: the lens jumps to the pointer instead of easing, and appears and fades at once.
  • Cost: with the pointer away it draws nothing. While it shows, it shades only around the lens: about 0.08 ms of GPU time a frame on the benchmark card, plus a copy of what is under it. See Performance.
