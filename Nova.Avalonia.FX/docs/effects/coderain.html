Code rain

CodeRain rains columns of glyphs down a terminal-style background. Each stream has a bright head and a fading trail, and the glyphs flip as it passes. The glyphs are dot-matrix shapes made up for each cell, not a font, so the rain looks the same on every platform. Use it behind a terminal, a "connecting" screen or a hacker-themed hero. It's a fill: it paints the host's shape under the child.

  • Light
  • Dark

Add code rain

Put the host around the panel, and leave the panel without a background so the rain shows through it. A dark, slightly see-through plate keeps text readable over the streams:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost CornerRadius="12">
        <fx:FXHost.Layers>
            <fx:CodeRain />
        </fx:FXHost.Layers>
        <Grid Height="240">
            <Border Background="#CC020A06" CornerRadius="8" Padding="12,8"
                    HorizontalAlignment="Center" VerticalAlignment="Center">
                <TextBlock Text="&gt; connected" Foreground="#E6FFF0"
                           FontFamily="Menlo, Consolas, monospace" FontSize="16" />
            </Border>
        </Grid>
    </fx:FXHost>
</UserControl>

Change the rain

GlyphSize is the height of a glyph cell in DIPs (14 by default); columns are about two thirds as wide. Density is the share of the columns that rain, Trail the length of a stream's trail in glyphs, and ChangeRate how often a glyph flips, per second (0: the glyphs never change). Color colors the trail, HeadColor the bright head, and BackgroundColor the terminal behind them.

An amber terminal with fewer, longer streams:

<fx:CodeRain Color="#FFB000" HeadColor="#FFF4D6" BackgroundColor="#0A0700"
             GlyphSize="18" Density="0.5" Trail="22" />

Each column falls at its own pace. Speed multiplies them all, and fills run on one shared clock, so code rain on different hosts, with the same settings, falls in step.

Rain over content

Set BackgroundColor to a transparent color to keep only the glyphs. Under the child, they then show wherever the child is see-through; with Placement="Over", they rain over the content:

<fx:FXHost CornerRadius="12">
    <fx:FXHost.Layers>
        <fx:CodeRain BackgroundColor="Transparent" Placement="Over" Density="0.3" />
    </fx:FXHost.Layers>
    <Border Width="320" Height="180" CornerRadius="12" Background="#0B1220" Padding="16">
        <TextBlock Text="Access granted" Foreground="White" FontSize="20" FontWeight="SemiBold" />
    </Border>
</fx:FXHost>

The glyphs are added as light, so they show best over dark content.

Properties

Property Type Default Description
Color Color #3CFF8F The color of the glyphs in a stream's trail.
HeadColor Color #E6FFF0 The color of the bright glyph at the head of each stream.
BackgroundColor Color #020A06 The color behind the glyphs; transparent shows what is behind the host. To rain over the content, also set Placement to Over.
GlyphSize double 14 Height of a glyph cell. Range 6–48 DIPs.
Density double 0.7 Share of the columns raining. Range 0.05–1 (5–100%).
Trail double 14 Length of a stream's trail, in glyphs. Range 2–40.
ChangeRate double 3 How often a glyph flips, per second. Range 0–20.
BorderWidth double 0 Width of a band inside the edge, DIPs. 0: the whole shape. Range 0–48.
UseMask bool false Paints only the child's own pixels (text, icons, a logo) instead of the shape: gradient text, a liquid-metal logo, holographic icons. It then goes over the child unless Placement says otherwise. The host captures the child to know its pixels: call RefreshMask after changing something deep inside it.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. On a fill, Intensity is its coverage, up to 1, and Seed picks which columns rain and their glyphs.

Notes

  • Light and dark surfaces: code rain doesn't change with the surface. Its default background is dark, so it looks the same in both themes; with a transparent background, the glyphs fade out over a light surface. See Light and dark surfaces.
  • Reduced motion: the streams and glyphs hold one fixed pose. See Reduced motion.
  • Cost: about 0.06 ms of GPU time a frame on the benchmark's 340×190 card, among the cheapest layers. The cost grows with the area. See Performance.
  • Bands and masks: like every fill, it has BorderWidth, which paints only a band inside the edge, and UseMask, which rains only inside the child's own pixels, such as large text. See Content masks.
