Plastic

A slab of plastic under one soft light: a base that keeps its color, a highlight sized by the light and the surface's roughness, and a faint sky at grazing angles near the rim. It can be glossy or matte, domed or dished like a keycap's top. Use it for keyboard keys, tactile buttons, toggles and toy-like tiles. It is a fill: it paints the host's shape and goes under the child. It doesn't move, so it is drawn once and costs nothing per frame after that.

  • Light
  • Dark

Add plastic

The fill goes under the child, so leave the child without a background:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost>
        <fx:FXHost.Layers>
            <fx:Plastic Preset="Glossy" Color="#D7263D" />
        </fx:FXHost.Layers>
        <Border Width="56" Height="56" CornerRadius="12">
            <TextBlock Text="esc" Foreground="#FFF1F2" FontWeight="SemiBold"
                       HorizontalAlignment="Center" VerticalAlignment="Center" />
        </Border>
    </fx:FXHost>
</UserControl>

Presets

Each preset sets Color, Roughness and Dome. Set any of them yourself to adjust a preset, as the red key above does with Color.

Value Description
Glossy (default) Warm off-white with a crisp highlight, slightly domed.
Matte Dark charcoal with a soft, broad sheen, slightly domed.
Dished A matte face dished like a keycap's top.

Make a row of keycaps

Each key gets its own host and layer. Pick a text color for the plastic under it: dark on the light presets, light on Matte, which is dark gray:

<StackPanel Orientation="Horizontal" Spacing="12">
    <fx:FXHost>
        <fx:FXHost.Layers><fx:Plastic Preset="Glossy" /></fx:FXHost.Layers>
        <Border Width="56" Height="56" CornerRadius="12">
            <TextBlock Text="⌘" FontSize="20" Foreground="#4B4740"
                       HorizontalAlignment="Center" VerticalAlignment="Center" />
        </Border>
    </fx:FXHost>
    <fx:FXHost>
        <fx:FXHost.Layers><fx:Plastic Preset="Dished" /></fx:FXHost.Layers>
        <Border Width="56" Height="56" CornerRadius="12">
            <TextBlock Text="A" FontSize="18" Foreground="#4B4740"
                       HorizontalAlignment="Center" VerticalAlignment="Center" />
        </Border>
    </fx:FXHost>
    <fx:FXHost>
        <fx:FXHost.Layers><fx:Plastic Preset="Matte" /></fx:FXHost.Layers>
        <Border Width="56" Height="56" CornerRadius="12">
            <TextBlock Text="⌥" FontSize="20" Foreground="#C7CAD1"
                       HorizontalAlignment="Center" VerticalAlignment="Center" />
        </Border>
    </fx:FXHost>
</StackPanel>

Shape the slab

Roughness goes from a small, sharp highlight (low) to a broad, soft one (high). Dome curves the face: positive values dome it, negative ones dish it. Bevel is the width of the rounded edge, and LightAngle moves the light: 0 is from above, 90 from the right.

<fx:Plastic Color="#2563EB" Roughness="0.3" Dome="0.6" Bevel="10" LightAngle="0" />

Properties

Property Type Default Description
Preset PlasticPreset Glossy A starting finish: sets Color, Roughness and Dome. Local values win. Values: Glossy, Matte, Dished.
Color Color #ECE8DE The plastic's color.
Roughness double 0.15 How rough the surface is: low is glossy with a tight highlight, high is matte with a broad, faint one. Range 0.05–1 (5–100%).
Dome double 0.35 Positive domes the face, negative dishes it. Range -1 to 1.
Bevel double 6 Width of the rounded rim, in DIPs. Range 0–48.
LightAngle double -29 Where the light comes from, degrees: 0 from above, 90 from the right; positive turns clockwise. Range -180 to 180.
BorderWidth double 0 Width of a band inside the edge, DIPs. 0: the whole shape. Range 0–48.
UseMask bool false Paints only the child's own pixels (text, icons, a logo) instead of the shape: gradient text, a liquid-metal logo, holographic icons. It then goes over the child unless Placement says otherwise. The host captures the child to know its pixels: call RefreshMask after changing something deep inside it.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale.

Notes

  • Intensity is the fill's coverage, from 0 to 1. Speed and Seed don't change plastic.
  • Still: plastic has no motion, so it requests no frames once drawn, and it looks the same under reduced motion.
  • Light and dark surfaces: plastic draws the same on both.
  • Like every fill, plastic can paint only the child's own pixels (text, an icon) with UseMask, or a band inside the edge with BorderWidth.
  • Cost: 0.042 ms of GPU time per redraw on a 340×190 card in the gallery's bench. See Performance.
