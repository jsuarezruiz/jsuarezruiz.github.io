Beams

Beams paints shafts of light that drift slowly sideways over a dark background, with light falling down them: a quiet, cinematic backdrop for a hero section, a launch announcement or a dark landing page. The shafts can lean, and they're brightest at the top, where they come in. It's a fill: it paints the host's shape under the child. For light traveling along a path between two controls, see Beam instead.

  • Light
  • Dark

Add beams

Put the host around the panel, and leave the panel without a background so the beams show through it.

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost CornerRadius="12">
        <fx:FXHost.Layers>
            <fx:Beams Count="7" Angle="12" Glow="0.7" />
        </fx:FXHost.Layers>
        <Grid Height="240">
            <StackPanel HorizontalAlignment="Center" VerticalAlignment="Center" Spacing="2">
                <TextBlock Text="Launch week" Foreground="White" FontWeight="Bold" FontSize="24"
                           HorizontalAlignment="Center" />
                <TextBlock Text="Five days of new features" Foreground="#AAB4D8" FontSize="12"
                           HorizontalAlignment="Center" />
            </StackPanel>
        </Grid>
    </fx:FXHost>
</UserControl>

Space and lean the shafts

Count is how many shafts cross the shape (12 by default). They're spaced evenly, so the count holds at any size: on a wider shape the shafts sit farther apart. Width is a shaft's average width in DIPs. A shaft is never wider than about two thirds of the space between shafts, so packed shafts stay separate, nor wider than a ninth of the shape's height, so a short shape shows streaks rather than blobs.

Angle leans the shafts, in degrees from upright: positive turns them clockwise, tops to the right. Glow sets the soft light around each shaft (1 by default, 0 for none, up to 2), and Color the light's color.

<fx:Beams Count="24" Width="8" Angle="-15" Glow="1.4" Color="#FDE68A" />

Each shaft drifts around its place at its own pace. Speed multiplies the clock, the drift and the falling light. Fills run on one shared clock, so beams on different hosts, with the same settings, move in step.

Put the beams over your own background

BackgroundColor is the color behind the beams (#06070D by default); its alpha is how opaque it is. A transparent background lets what is under the host show, such as a gradient on a border around it:

<Border CornerRadius="12">
    <Border.Background>
        <LinearGradientBrush StartPoint="0%,0%" EndPoint="0%,100%">
            <GradientStop Color="#1E1B4B" Offset="0" />
            <GradientStop Color="#020617" Offset="1" />
        </LinearGradientBrush>
    </Border.Background>
    <fx:FXHost CornerRadius="12">
        <fx:FXHost.Layers>
            <fx:Beams BackgroundColor="Transparent" Color="#A5B4FC" />
        </fx:FXHost.Layers>
        <Grid Height="240" />
    </fx:FXHost>
</Border>

The beams are added as light, so keep what is under them dark.

Properties

Property Type Default Description
Color Color #C8D2FF The color of the shafts and of the light falling down them.
BackgroundColor Color #06070D Behind the beams; transparent lets what is under the host show.
Count int 12 How many shafts cross the shape. Range 1–48.
Width double 14 How wide a shaft is, on average; never wider than about two thirds of the space between shafts, or a ninth of the shape's height. Range 2–80 DIPs.
Glow double 1 The soft light around each shaft, a multiple: 1 is the default, 0 none. Range 0–2.
Angle double 0 How far the shafts lean from upright, degrees: 0 upright; positive turns them clockwise (tops to the right). Range -60 to 60.
BorderWidth double 0 Width of a band inside the edge, DIPs. 0: the whole shape. Range 0–48.
UseMask bool false Paints only the child's own pixels (text, icons, a logo) instead of the shape: gradient text, a liquid-metal logo, holographic icons. It then goes over the child unless Placement says otherwise. The host captures the child to know its pixels: call RefreshMask after changing something deep inside it.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. On a fill, Intensity is its coverage, up to 1, and Seed picks each shaft's width and pace.

Notes

  • Light and dark surfaces: beams don't change with the surface. The default background is dark, so they look the same in both themes; with a transparent background, the shafts fade out over a light surface. See Light and dark surfaces.
  • Reduced motion: the shafts and their falling light hold one fixed pose. See Reduced motion.
  • Cost: about 0.11 ms of GPU time a frame on the benchmark's 340×190 card. Each pixel only looks at the five nearest shafts, so a higher Count doesn't cost more. The cost grows with the area. See Performance.
  • Bands and masks: like every fill, it has BorderWidth, which paints only a band inside the edge, and UseMask, which paints only the child's own pixels, such as large text. See Content masks.
