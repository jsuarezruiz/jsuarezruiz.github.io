Silk

A background of soft satin: a few broad folds lit by one soft light, shading into their creases with a gentle sheen along the ridges, flowing slowly. It is calm enough to sit behind text, so it suits hero sections, sign-in pages, welcome screens and feature cards. It is a fill: it paints the host's shape in one color and its shades, and goes under the child.

  • Light
  • Dark

Add silk

The fill goes under the child, so leave the child without a background:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost CornerRadius="16">
        <fx:FXHost.Layers>
            <fx:Silk Preset="Midnight" Scale="120" />
        </fx:FXHost.Layers>
        <Border Width="240" Height="140">
            <StackPanel HorizontalAlignment="Center" VerticalAlignment="Center" Spacing="4">
                <TextBlock Text="Welcome back" Foreground="White" FontWeight="Bold" FontSize="20"
                           HorizontalAlignment="Center" />
                <TextBlock Text="Sign in to continue" Foreground="#C7D2FE" FontSize="12"
                           HorizontalAlignment="Center" />
            </StackPanel>
        </Border>
    </fx:FXHost>
</UserControl>

Presets

Each preset sets Color and Sheen. Set either yourself to adjust a preset.

Value Description
Mauve (default) A muted mauve.
Midnight Deep navy.
Pearl A pale, warm pearl.
Rose Dusty rose.
Emerald Deep green.

Use your own color

Silk is shaded from a single Color: the folds darken into their creases and lighten along the ridges. A brand color works directly:

<fx:Silk Color="#7C3AED" />

Pick the text color by the silk's: light text on every preset but Pearl, and dark text on Pearl and other pale colors.

Shape the folds

Scale sets how wide the folds are, Angle which way they run (0 is top to bottom), and Sheen how much light runs along the ridges. Speed sets how fast they flow:

<fx:Silk Preset="Pearl" Scale="260" Angle="20" Sheen="0.5" Speed="0.5" />

Properties

Property Type Default Description
Preset SilkPreset Mauve A starting Color and Sheen; local values win. Values: Mauve, Midnight, Pearl, Rose, Emerald.
Color Color #7B7481 The fabric's color; the creases shade it darker and the sheen paler.
Scale double 160 How wide the folds are. Range 30–600 DIPs.
Sheen double 1 The light along the ridges. Range 0–2.
Angle double -30 Which way the folds run, degrees: 0 top to bottom; positive turns them clockwise. Range -180 to 180.
BorderWidth double 0 Width of a band inside the edge, DIPs. 0: the whole shape. Range 0–48.
UseMask bool false Paints only the child's own pixels (text, icons, a logo) instead of the shape: gradient text, a liquid-metal logo, holographic icons. It then goes over the child unless Placement says otherwise. The host captures the child to know its pixels: call RefreshMask after changing something deep inside it.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale.

Notes

  • Intensity is the fill's coverage, from 0 to 1. Seed doesn't change silk.
  • Light and dark surfaces: silk draws the same on both; it is an opaque background in its own color.
  • Reduced motion: the folds hold one pose. See Reduced motion.
  • Cost: 0.057 ms of GPU time per frame on a 340×190 card in the gallery's bench. See Performance.
  • Like every fill, silk can paint only the child's own pixels with UseMask, or a band inside the edge with BorderWidth.
