Spotlight

Spotlight is a soft light that follows the pointer across the host's shape and lights the stretch of border nearest to it. It fades in when the pointer arrives and out when it leaves, and it reacts to a pointer just outside the shape too, so the border lights up as the pointer approaches. Use it on pricing cards, feature tiles or any surface that should answer the pointer. It draws over the child, and while the pointer is away it draws nothing.

  • Light
  • Dark

Add a spotlight

Put a Spotlight in the layers of the card it should light. Radius sets the size of the light.

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost CornerRadius="14">
        <fx:FXHost.Layers>
            <fx:Spotlight Radius="140" />
        </fx:FXHost.Layers>
        <Border Width="230" Height="130" CornerRadius="14" Padding="18,14" Background="#15171C">
            <StackPanel Spacing="6">
                <TextBlock Text="Pro" FontWeight="Bold" FontSize="16" Foreground="White" />
                <TextBlock Text="Move the pointer over me" FontSize="12" Foreground="#A1A1AA" />
            </StackPanel>
        </Border>
    </fx:FXHost>
</UserControl>

Fill is the light on the surface and Rim the light on the border near the pointer, as wide as RimWidth.

Color the light for light themes

The default light is white, which shows on a dark card and vanishes on a white one. On a light theme, give it a color, for example from a theme resource:

<fx:Spotlight Color="{DynamicResource SpotlightColor}" Radius="140" />

Define SpotlightColor per theme, such as an accent blue for Light and white for Dark; see Theme the colors. On an accent-colored button, a light in the accent color vanishes too: use white there.

Tune how it follows

PointerReach is how far outside the shape the pointer still lights it, 48 DIPs by default; set it to 0 to light the card only while the pointer is over it. FollowTime is how long the light takes to catch up with the pointer, and Fade how long it takes to appear and to fade out.

<fx:Spotlight PointerReach="120" FollowTime="0.15" Fade="0.5" />

Point it from code

PointAt aims the light as if the pointer were there: for keyboard focus or a guided tour. Pass null to fade it out; the pointer takes over again when it moves.

// CardSpotlight is the Spotlight layer, CardHost its FXHost, SaveButton a button inside the card.
SaveButton.GotFocus += (_, _) =>
{
    var center = new Point(SaveButton.Bounds.Width / 2, SaveButton.Bounds.Height / 2);
    CardSpotlight.PointAt(SaveButton.TranslatePoint(center, CardHost));
};
SaveButton.LostFocus += (_, _) => CardSpotlight.PointAt(null);

Methods

Method Description
PointAt(Point? at) Points the light at at (host coordinates), as if the pointer were there: for keyboard focus or a guided tour. Null fades it out. The pointer takes over when it moves.

Properties

Property Type Default Description
Color Color #FFFFFF The light's color.
Radius double 160 Radius of the light. Range 20–600 DIPs.
Fill double 0.14 Light on the surface. Range 0–1 (0–100%).
Rim double 0.9 Light on the border near the pointer. Range 0–2.
RimWidth double 1.5 Width of the lit border, in DIPs. Range 0.5–6.
PointerReach double 48 How far outside the shape the pointer still lights it. Range 0–300 DIPs.
FollowTime double 0.08 How long the light takes to catch up with the pointer (a time constant). Range 0–0.5 seconds.
Fade double 0.3 How long the light takes to appear and to fade out. Range 0–1.5 seconds.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. On a spotlight, Intensity dims the layer; Speed and Seed don't apply.

Notes

  • Light and dark surfaces. On a dark surface the light adds to the card. On a light surface it draws as tinted haze in its own color; a white or gray light stays white. See Light and dark surfaces.
  • Reduced motion. The light jumps to the pointer instead of easing, and appears and fades at once. See Reduced motion.
  • Cost. Nothing while the pointer is away. While it moves, each frame repaints only around the light: about 0.03 ms of GPU time a frame on the bench's 340×190 card. See Performance.
  • The pointer. The host listens to the window's pointer only while a layer that follows it is active, so the child doesn't need to be hit-testable. See Layers that follow the pointer.
