Spoiler

Spoiler hides the host's content until it is revealed, as messaging apps hide spoilers: shimmering dust over a heavy blur, a mosaic, or a solid cover. A tap opens it in a soft circle from the tap point. Use it for spoilers, answers to a quiz, sensitive values such as a balance or a code, or redaction in screenshots and demos. It draws over the content.

  • Light
  • Dark

Add a spoiler

Wrap the text, or any element, in a host with the layer. A tap reveals it; here it covers itself again after four seconds:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost CornerRadius="6" Cursor="Hand" HorizontalAlignment="Center" VerticalAlignment="Center">
        <fx:FXHost.Layers>
            <fx:Spoiler HideAfter="4" />
        </fx:FXHost.Layers>
        <TextBlock Text="It was the gardener all along." FontSize="15" FontWeight="SemiBold" />
    </fx:FXHost>
</UserControl>

Styles

Value Description
Dust (default) Shimmering dust over a heavy blur of the content.
Pixelate A mosaic of the content: redaction for screenshots and demos.
Solid Dust over a solid cover color (no copy of what is behind).

Reveal and cover from code

IsRevealed is false by default and binds both ways, so a tap, Reveal() and Hide() also update a bound view-model property. Reveal(from) opens the circle from a point in the host's coordinates, or from the center without one. Hide() fades the cover back in.

<fx:Spoiler x:Name="AnswerSpoiler" IsRevealed="{Binding IsAnswerShown}" />

private void OnShowAnswerClick(object? sender, RoutedEventArgs e) => AnswerSpoiler.Reveal();

private void OnNextQuestionClick(object? sender, RoutedEventArgs e) => AnswerSpoiler.Hide();

Duration is how long the reveal takes to open, and the cover to fade back in (0.7 seconds by default). The layer's Speed paces the dust, not the reveal. Set RevealOnPress="False" when only your code should reveal it.

Cover it again after a while

HideAfter covers the content again that many seconds after a reveal has finished opening. At 0, the default, or Infinity, it stays revealed. For a one-time code or a balance:

<fx:Spoiler Style="Pixelate" CellSize="10" HideAfter="8" />

Redact or cover

Pixelate turns the content into a mosaic of CellSize cells, without dust: redaction for screenshots and demos. Solid lays a CoverColor with dust over it instead of a copy of what is behind; set it to the surface behind the content. The dust is set by Density, DustSize, DustSpeed and DustColor; a transparent DustColor, the default, contrasts with whatever it covers.

<fx:Spoiler Style="Solid" CoverColor="#2a2d34" Density="0.4" />

Methods

Call Reveal and Hide to open and cover from code.

Method Description
Reveal(Point? from = null) Reveals the content, opening from from (host coordinates) or the center.
Hide() Covers the content again.

Properties

Property Type Default Description
Style SpoilerStyle Dust How the content is hidden: dust over a blur, a mosaic, or dust over a solid cover. Values: Dust, Pixelate, Solid.
IsRevealed bool false Whether the content is revealed: true opens the cover in a soft circle, false covers it again. Binds both ways, so a tap updates it.
RevealOnPress bool true Reveals where the pointer is pressed on the host.
HideAfter double 0 Seconds the content stays revealed, counted from when the opening finishes, before it is covered again (0 or Infinity: it stays revealed). Range 0–60.
Duration double 0.7 How long the cover takes to open on a reveal, and to fade back in on a hide. Range 0–3 seconds.
DustColor Color #00FFFFFF The dust's color. Transparent: contrasts with what it covers. Applies to the Dust and Solid styles.
CoverColor Color #2A2D34 The cover for the Solid style (match the surface behind the content). Applies to the Solid style.
Density double 0.3 How much dust there is: the share of places holding a speck (0: none). Range 0–1 (0–100%). Applies to the Dust and Solid styles.
DustSize double 1.6 Size of a dust speck, in DIPs. Range 0.3–4. Applies to the Dust and Solid styles.
DustSpeed double 1 How fast the dust swirls and twinkles, a multiple (0: still). Range 0–4. Applies to the Dust and Solid styles.
Blur double 6 Blur under the dust. Range 1–20 DIPs. Applies to the Dust style.
CellSize double 8 Mosaic cell for the Pixelate style. Range 2–40 DIPs. Applies to the Pixelate style.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale.

Notes

  • Pixels only. The spoiler covers what is drawn. The content itself is still there: screen readers read it, and it takes focus and input as before.
  • Reads the backdrop. Dust and Pixelate copy what is behind them, which holds the content. Keep ancestors opaque, or use Solid, which needs no copy. See Layers that read the backdrop.
  • Reduced motion. Revealing and covering switch at once, and the dust holds still. See the poses.
  • Cost. The dust over a blur takes about 0.32 ms of GPU time a frame on a card, 0.92 ms on a 700×500 panel. Once revealed, it draws nothing. See What a layer costs.
