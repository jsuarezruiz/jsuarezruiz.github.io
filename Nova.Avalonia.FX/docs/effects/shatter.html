Shatter

Shatter breaks the host's content into glass shards that fly apart and fall, or turns it to dust that blows away, and brings it back together to show it. It suits delete, dismiss and undo. Like Reveal, it captures the content, hides the real element while the pieces fly, and hands it back once shown. The pieces are drawn with Skia straight from the capture.

  • Light
  • Dark

Add a shatter

Bind IsShown, or call Hide() and Show(). Here a switch breaks the card and puts it back together:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <StackPanel Spacing="12" HorizontalAlignment="Center" VerticalAlignment="Center">
        <fx:FXHost CornerRadius="14" ZIndex="1">
            <fx:FXHost.Layers>
                <fx:Shatter Pieces="30" IsShown="{Binding #ShownSwitch.IsChecked}" />
            </fx:FXHost.Layers>
            <Border Width="220" Height="96" CornerRadius="14" Padding="16" Background="#15171c">
                <TextBlock Text="Old draft" Foreground="White" FontWeight="SemiBold" />
            </Border>
        </fx:FXHost>
        <ToggleSwitch x:Name="ShownSwitch" IsChecked="True" OnContent="Whole" OffContent="Broken" />
    </StackPanel>
</UserControl>

Styles

Value Description
Shards (default) Glass shards that fly apart and fall.
Dust Fine dust that blows away on the wind, from one side or from the point given.

Break it from a point

Hide(toward) takes the point the break starts from, in the host's coordinates. Shards are cut around it, smaller near it; dust leaves from it outward. Show(from) brings the pieces back toward it. With no point, shards break from the center, and dust leaves from the side the wind blows toward (WindAngle).

private void OnCardPressed(object? sender, PointerPressedEventArgs e)
{
    var at = e.GetPosition(CardHost);
    if (CardShatter.IsShown) CardShatter.Hide(at);
    else CardShatter.Show(at);
}

The hidden element keeps its place in the layout and still takes presses and keyboard focus, so pressing where the card was brings it back here. Set IsHitTestVisible from the same state if it shouldn't.

Delete with undo

IsShown is true by default and binds both ways, so Hide() and Show() also update a bound view-model property. Bind it to a property and change that:

// ViewModelBase is any base class that raises PropertyChanged.
public class MessageViewModel : ViewModelBase
{
    private bool _isShown = true;

    public bool IsShown
    {
        get => _isShown;
        set => SetProperty(ref _isShown, value);
    }

    public void Delete() => IsShown = false;

    public void Undo() => IsShown = true;
}

<fx:Shatter Style="Dust" IsShown="{Binding IsShown}" />

Set IsShown="False" in XAML to start hidden, with no transition. If the host shrinks while the pieces fly (a list row collapsing as it is removed), the pieces scale with it rather than being cut again.

Set the pace

Duration is the length of the break, or of the landing, in seconds (1.1 by default). The layer's Speed doesn't apply, and a change applies from the next transition. Force sets how hard the shards fly out and Gravity how fast they fall. For dust, DustSize sets the grain: larger grains keep large content quick.

With nothing to capture (no child, a child that isn't visible or isn't laid out yet, or IsActive off) the layer switches at once. To play it as a view opens, start hidden and call Show() from the view's Loaded event; Reveal shows the pattern.

Methods

Show and Hide play the transition from code, from or toward a point.

Method Description
Show(Point? from = null) Shows the content, playing the layer's transition from from (host coordinates). Null: the layer's own point.
Hide(Point? toward = null) Hides the content, playing the layer's transition toward toward (host coordinates). Null: the layer's own point.

Properties

Property Type Default Description
Style ShatterStyle Shards Whether the content breaks into glass shards or blows away as dust. Values: Shards, Dust.
IsShown bool true Whether the content is shown. Setting it false breaks the content apart; true brings it back together.
Duration double 1.1 How long the transition takes, in seconds. Range 0.2–4.
Pieces int 36 About how many shards. Range 6–120. Applies to the Shards style.
Force double 1 How hard the pieces fly out: the shards' burst, or how hard the wind blows the dust away. Range 0–3.
Gravity double 1 How strongly the pieces fall, a multiple of the default (dust falls only gently; 0: they don't fall). Range 0–3.
EdgeHighlight double 0.5 The light catching each shard's edges. Range 0–1 (0–100%). Applies to the Shards style.
DustSize double 3 The size of a grain of dust (larger grains for large content, to stay quick). Range 1–8 DIPs. Applies to the Dust style.
WindAngle double -25 The way the wind blows the dust, degrees: 0 to the right, -90 up; positive turns clockwise. Range -180 to 180. Applies to the Dust style.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. Seed changes how the shards are cut.

Notes

  • Light and dark. On a dark surface the light catches each shard's edges in white. On a light one the edges are dark lines, and the shards cast a soft shadow on the page, so a white card's pieces still show. See Light and dark surfaces.
  • Reduced motion. It becomes a fade of at most a quarter of a second, with no flying. See the poses.
  • Cost. The shards are Skia paths: 0.1–0.4 ms of CPU time a frame while they fly. Dust takes 0.13–0.6 ms of CPU time while it blows. Both swing from run to run. At rest the layer draws nothing. RenderScale doesn't apply. See What a layer costs.
  • Room to fly. Shards fly out and fall well past the host, and dust drifts past its edge. A clipping ancestor cuts them, and a later sibling covers them: leave room, and give the host a higher ZIndex.
