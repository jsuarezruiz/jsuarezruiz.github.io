Tilt

Tilt leans the host toward the pointer in 3D and grows it a little, while a glare slides across it with the pointer, like a card turned under a light. Use it on cards, passes, product tiles and album art. The lean is a perspective render transform on the host, so the host's other layers, such as a glow or a shadow, lean with it. The glare is drawn over the content.

  • Light
  • Dark

Add a tilt

Add the layer to a host around the card, and leave a little room around it for the lean:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost CornerRadius="16" Margin="24" HorizontalAlignment="Center" VerticalAlignment="Center">
        <fx:FXHost.Layers>
            <fx:Tilt MaxAngle="14" Glare="0.45" />
        </fx:FXHost.Layers>
        <Border Width="196" Height="120" CornerRadius="16" Padding="16">
            <Border.Background>
                <LinearGradientBrush StartPoint="0%,0%" EndPoint="100%,100%">
                    <GradientStop Color="#1e3a8a" Offset="0" />
                    <GradientStop Color="#7c3aed" Offset="0.6" />
                    <GradientStop Color="#db2777" Offset="1" />
                </LinearGradientBrush>
            </Border.Background>
            <TextBlock Text="NOVA PASS" Foreground="White" FontWeight="SemiBold" />
        </Border>
    </fx:FXHost>
</UserControl>

Shape the lean

MaxAngle is the most the host leans, in degrees (0: it stays flat); a negative angle leans away from the pointer instead. Lift is how much it grows while pointed at (1: not at all), and Perspective how far the eye is: nearer looks deeper.

<fx:Tilt MaxAngle="-8" Lift="1.05" Perspective="600" />

Glare sets the strength of the glare and GlareColor its color. On bare text, set Glare to 0: the glare would light up the text's whole box.

Reach and pace

The layer listens to the window's pointer, so buttons inside the card don't block it, and it reads the pointer against the host as laid out, so the lean never chases itself. PointerReach is how far outside the content the pointer still leans it (0 by default: only over it). FollowTime is how long the lean and the glare take to catch up with the pointer; once the pointer leaves, the host eases back flat.

Aim it from code

PointAt(at) leans the host toward a point in its own coordinates, as if the pointer were there: for keyboard focus, a tour or a demo. PointAt(null) lets it settle flat, and the pointer takes over again when it moves.

PassHost.GotFocus += (_, _) =>
{
    // Lean toward the top right corner while the card has focus.
    PassTilt.PointAt(new Point(PassHost.Bounds.Width, 0));
};
PassHost.LostFocus += (_, _) => PassTilt.PointAt(null);

Methods

Call PointAt to aim the lean from code.

Method Description
PointAt(Point? at) Leans toward at (host coordinates) as if the pointer were there: for keyboard focus or a demo. Null lets it settle flat. The pointer takes over when it moves.

Properties

Property Type Default Description
MaxAngle double 10 The most it leans, degrees (0: it stays flat). Negative leans away from the pointer instead. Range -30 to 30.
Lift double 1.03 How much it grows while the pointer is over it (1: not at all). Range 1–1.15.
Perspective double 900 How far the eye is from the content: nearer looks deeper. Range 200–3000 DIPs.
Glare double 0.35 The glare's strength. Range 0–1 (0–100%).
GlareColor Color #FFFFFF The glare's color.
FollowTime double 0.12 How long the lean and the glare take to catch up with the pointer (a time constant). Range 0–0.6 seconds.
PointerReach double 0 How far outside the content the pointer still leans it. Range 0–200 DIPs.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. Tilt follows the pointer, not a clock, so Speed and Seed do nothing.

Notes

  • The host's own transform. While it leans, the tilt takes the place of a RenderTransform set on the host. The host's own value comes back once it settles flat. Don't animate the host's RenderTransform while it tilts.
  • Room around it. Leaning and lifting swing the corners past the host's bounds. Leave a margin, or a clipping ancestor cuts them.
  • Light and dark. The glare draws the same on both surfaces, in GlareColor.
  • Reduced motion. The host stays flat; only the glare follows the pointer. See the poses.
  • Cost. Under 0.05 ms of GPU time a frame on a card. The lean is eased on the UI thread's animation frames only while it moves, and the transform is removed once flat. See What a layer costs.
