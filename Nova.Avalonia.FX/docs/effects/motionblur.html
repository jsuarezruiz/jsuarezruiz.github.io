Motion blur

Motion blur draws a smear of the host's content along its motion, behind it, while the host moves: a slide-in, a drag, a fling, a transform animation. It reads how the host moves in its window every frame, so any movement counts, whatever moves it. Still, it draws nothing. The content itself stays sharp; the smear trails behind it like a wake.

  • Light
  • Dark

Add motion blur

Add the layer to a host that moves. Here an animation slides the host back and forth:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost CornerRadius="14" HorizontalAlignment="Center" VerticalAlignment="Center">
        <fx:FXHost.RenderTransform>
            <TranslateTransform />
        </fx:FXHost.RenderTransform>
        <fx:FXHost.Styles>
            <Style Selector="fx|FXHost">
                <Style.Animations>
                    <Animation Duration="0:0:1.2" IterationCount="INFINITE" PlaybackDirection="Alternate" Easing="SineEaseInOut">
                        <KeyFrame Cue="0%"><Setter Property="TranslateTransform.X" Value="-80" /></KeyFrame>
                        <KeyFrame Cue="100%"><Setter Property="TranslateTransform.X" Value="80" /></KeyFrame>
                    </Animation>
                </Style.Animations>
            </Style>
        </fx:FXHost.Styles>
        <fx:FXHost.Layers>
            <fx:MotionBlur Shutter="0.06" />
        </fx:FXHost.Layers>
        <Border Width="110" Height="70" CornerRadius="14" Background="#3b82f6">
            <TextBlock Text="Swoosh" Foreground="White" FontWeight="SemiBold"
                       HorizontalAlignment="Center" VerticalAlignment="Center" />
        </Border>
    </fx:FXHost>
</UserControl>

Smear a slide-in

Anything that moves the host works: a transition on its RenderTransform, a change of Canvas.Left, a drag, a layout change, or a parent that moves. This drawer slides in with a transition:

<fx:FXHost x:Name="Drawer" RenderTransform="translateX(-320px)">
    <fx:FXHost.Transitions>
        <Transitions>
            <TransformOperationsTransition Property="RenderTransform" Duration="0:0:0.35" Easing="CubicEaseOut" />
        </Transitions>
    </fx:FXHost.Transitions>
    <fx:FXHost.Layers>
        <fx:MotionBlur />
    </fx:FXHost.Layers>
    <Border Width="300" Height="400" Background="#15171c" />
</fx:FXHost>

// using Avalonia.Media.Transformation;
Drawer.RenderTransform = TransformOperations.Parse("translateX(0px)");

Tune the smear

Shutter is how long the virtual shutter stays open, in seconds: longer smears further. MaxLength caps the smear in DIPs, and Strength sets how strongly it shows.

<fx:MotionBlur Shutter="0.08" MaxLength="160" Strength="0.6" />

The smear is drawn from a capture of the content, which the host takes again when the content changes. After changing something deep inside it, call RefreshMask() on the host; see Content masks.

Properties

Property Type Default Description
Shutter double 0.05 How long the virtual shutter stays open: longer smears further. Range 0.005–0.2 seconds.
Strength double 0.75 How opaque the smear is (0: none). Range 0–1 (0–100%).
MaxLength double 120 The longest smear. Range 4–400 DIPs.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. Motion blur follows the host, not a clock, so Speed and Seed do nothing.

Notes

  • Scrolling counts. A host in a scrolling list smears while the list scrolls. Set IsActive to false where that isn't wanted.
  • Room behind it. The smear is drawn behind the content and reaches up to MaxLength past the host, so a clipping ancestor cuts it.
  • Light and dark. It draws the same on both surfaces, in the content's own colors.
  • Reduced motion. It draws nothing. See Reduced motion.
  • Cost. About 0.15 ms of GPU time a frame while the host moves, and nothing once it stops. See What a layer costs.
