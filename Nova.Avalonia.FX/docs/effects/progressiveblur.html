Progressive blur

ProgressiveBlur blurs what is behind the host more and more toward one edge, from sharp to fully blurred, so content fades into a bar instead of meeting a hard line. Use it for a header or a tab bar over a scrolling list, or a caption over a photo. Every point sees a real blur, not a mix of sharp and blurred, and Tint fades toward the bar's own surface. It draws under the child and shows what is drawn behind the host, so it needs content behind it.

  • Light
  • Dark

Add a progressive blur

Lay a header over a scrolling list: the list first, then the host on top of it in the same Grid. The header's child has no background, so the blurred list shows through it:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <Grid>
        <ScrollViewer>
            <ItemsControl ItemsSource="{Binding Messages}" Margin="0,70,0,0" />
        </ScrollViewer>
        <fx:FXHost VerticalAlignment="Top">
            <fx:FXHost.Layers>
                <fx:ProgressiveBlur Blur="14" Tint="#99FFFFFF" />
            </fx:FXHost.Layers>
            <Border Height="70">
                <TextBlock Text="Inbox" FontSize="18" FontWeight="Bold" Margin="16,12,0,0" />
            </Border>
        </fx:FXHost>
    </Grid>
</UserControl>

The top margin on the list lets its first item start below the bar; as it scrolls, items slide under it.

Give it something to blur

The layer copies the region of the window behind the host just before it draws (see Layers that read the backdrop). So:

  • The content goes first. Only what is drawn before the host is blurred: put the list before the host in the Grid, or give the host a higher ZIndex. Controls drawn after the host sit in front of the bar.
  • Keep the child see-through. The blur draws under the child, so a Background on the child hides it. The bar's title and buttons stay sharp on top.
  • Keep ancestors opaque. Inside an offscreen layer (an ancestor with Opacity below 1, an effect, or a clip that needs a layer) the copy can't see that ancestor's content.

Choose the edge and the ramp

Edge is where the blur is strongest: Top (the default) for a header, Bottom for a tab bar, Left or Right for a side panel. Ramp is how much of the shape the ramp covers from that edge, and Blur the blur at the edge:

<fx:ProgressiveBlur Edge="Bottom" Ramp="0.6" Blur="24" />

Tint it per theme

Tint is the color the blur fades toward at the strong edge, and its alpha is how much: the bar's own surface. Give it a value per theme, as the gallery does with #99FFFFFF on light and #991B1D22 on dark:

<fx:ProgressiveBlur Tint="{DynamicResource HeaderTintColor}" />

See Light and dark surfaces for theme resources.

Properties

Property Type Default Description
Blur double 16 Blur at the strongest edge, DIPs. Range 1–64.
Edge FXEdge Top The edge where the blur is strongest. Values: Top, Bottom, Left, Right.
Ramp double 1 How much of the shape the ramp covers, from the strong edge. Range 0.05–1 (5–100%).
Tint Color #00FFFFFF A color the blur fades toward at the strong edge; its alpha is how much (a bar's surface).

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. The blur is still, so Speed and Seed don't apply.

Notes

  • Light and dark surfaces: it draws the same on both; only the Tint should change.
  • Reduced motion: the blur has no motion of its own, so nothing changes.
  • Cost: about 1.0 ms of GPU time a frame on the benchmark card, the most of any layer, for its five copies of what is behind it (sharp, then blurred by an eighth, a quarter, a half and all of Blur). It doesn't animate, so it only redraws when what is behind it changes, such as while the list scrolls. See Performance.
