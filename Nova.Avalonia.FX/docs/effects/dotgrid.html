Dot grid

DotGrid draws a grid of small squares or dots that flicker at random, each fading between levels: a quiet, technical background for a dashboard, an empty state or a sign-in page. Dots near the pointer light up and grow, and a press sends a ring out across the grid. It's a fill that draws only the dots, under the child, so whatever is behind the host shows between them.

  • Light
  • Dark

Add a dot grid

Put the host around the panel. A Transparent background on the panel lets the dots show through and makes the whole panel take presses, so a press anywhere sends a ripple.

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost x:Name="DotsHost" CornerRadius="12">
        <fx:FXHost.Layers>
            <fx:DotGrid x:Name="Dots" Spacing="12" />
        </fx:FXHost.Layers>
        <Border Height="220" Background="Transparent">
            <TextBlock Text="No projects yet" HorizontalAlignment="Center" VerticalAlignment="Center" />
        </Border>
    </fx:FXHost>
</UserControl>

To give the panel a color of its own, put that background on a container around the host.

Shape the dots

The dots are squares by default; IsRound="True" makes them round. Spacing is the distance between dot centers and DotSize their size, both in DIPs. MaxOpacity is how strong the brightest dots get at rest, and Floor the dimmest they get, as a share of the brightest. Lit dots go most of the way to full strength, whatever MaxOpacity is. FlickerRate is how often each dot changes level a second; at 0 the grid is still and asks for frames only while the pointer moves over it or a ring runs.

<fx:DotGrid IsRound="True" Spacing="16" DotSize="2.5" Color="#94A3B8"
            MaxOpacity="0.35" FlickerRate="0" />

Light up around the pointer

Dots within HoverRadius DIPs of the pointer (90 by default) light up and grow, and they ease after it as it moves. The host listens to the window's pointer, so this works over any part of the panel. Set HoverRadius="0" to turn it off.

PointAt lights the dots from code, as if the pointer were there, for example around a field with keyboard focus. Pass null to let them go:

EmailBox.GotFocus += (_, _) =>
{
    var center = new Point(EmailBox.Bounds.Width / 2, EmailBox.Bounds.Height / 2);
    Dots.PointAt(EmailBox.TranslatePoint(center, DotsHost));
};
EmailBox.LostFocus += (_, _) => Dots.PointAt(null);

Send ripples

With RippleOnPress on (the default), a press sends a ring out from where it lands; the dots it passes light up. RippleSpeed is how fast the ring travels, in DIPs a second, and RippleWidth how wide it is. A ring fades once it has crossed the shape, and up to four run at once: a fifth replaces the oldest.

Ripple sends one from code, from a point in the host's coordinates or, without one, from the center:

// New results arrived: ripple from the middle of the grid.
Dots.Ripple();

Methods

Call these to light the grid or send a ring from code: for keyboard focus, a guided tour, or an event in your app.

Method Description
Ripple(Point? at = null) Sends a ring out across the grid from at (host coordinates), or from the center.
PointAt(Point? at) Lights the dots around at (host coordinates) as if the pointer were there; null lets them go.

Properties

Property Type Default Description
Color Color #7C8CFF The dots' color.
Spacing double 10 Distance between dot centers, in DIPs. Range 3–60.
DotSize double 3 Width of a dot, in DIPs; dots near the pointer or a ripple grow up to 1.8 times as wide. Range 0.5–30.
FlickerRate double 0.8 Changes of each dot's level per second (0: still). Range 0–6.
MaxOpacity double 0.5 How opaque the brightest dots are; dots near the pointer or a ripple go most of the way to full. Range 0–1 (0–100%).
Floor double 0.15 The dimmest a dot gets, as a share of the brightest. Range 0–1 (0–100%).
IsRound bool false Draws round dots instead of squares.
HoverRadius double 90 How far from the pointer dots light up and grow, DIPs. 0: they don't follow it. Range 0–400.
RippleOnPress bool true Whether a press sends a ripple out from where it lands.
RippleSpeed double 420 How fast a ripple's ring travels, DIPs a second. Range 60–2000 DIPs per second.
RippleWidth double 26 How wide a ripple's ring is. Range 4–120 DIPs.
BorderWidth double 0 Width of a band inside the edge, DIPs. 0: the whole shape. Range 0–48.
UseMask bool false Paints only the child's own pixels (text, icons, a logo) instead of the shape: gradient text, a liquid-metal logo, holographic icons. It then goes over the child unless Placement says otherwise. The host captures the child to know its pixels: call RefreshMask after changing something deep inside it.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. On a fill, Intensity is its coverage, up to 1.

Notes

  • Light and dark surfaces: the dots are drawn in Color on any surface. The default blue reads on both; for other colors, pick one per theme. See Light and dark surfaces.
  • Reduced motion: each dot holds one level, the lit dots jump to the pointer instead of easing, and presses send no ripples. See Reduced motion.
  • Cost: about 0.05 ms of GPU time a frame on the benchmark's 340×190 card, among the cheapest layers. See Performance.
  • Shared clock: fills run on one shared clock, so dot grids on different hosts, with the same settings, flicker in step.
  • Pointer and presses: see One-shots and the pointer for how presses and the pointer reach a layer.
  • Bands and masks: like every fill, it has BorderWidth, which paints only a band inside the edge, and UseMask, which paints only the child's own pixels, such as large text. See Content masks.
