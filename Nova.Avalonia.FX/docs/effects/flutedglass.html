Fluted glass

FlutedGlass turns the host into reeded glass: parallel convex ribs, each a cylindrical lens that shows a squeezed, flipped strip of what is behind it, with a color split toward its edges, a sheen along its lit side and a shaded groove. Use it for a privacy panel, a decorative header, or a card that keeps a busy picture behind it readable. Like Glass, it draws under the child and shows what is drawn behind the host, so it needs something behind it and a see-through child.

  • Light
  • Dark

Add fluted glass

Put the host over the content it should bend, here a photo in the same Grid, and give it a child without a background:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <Grid>
        <Image Source="/Assets/photo.jpg" Stretch="UniformToFill" />
        <fx:FXHost HorizontalAlignment="Center" VerticalAlignment="Center" CornerRadius="16">
            <fx:FXHost.Layers>
                <fx:FlutedGlass />
            </fx:FXHost.Layers>
            <Border Width="220" Height="120" />
        </fx:FXHost>
    </Grid>
</UserControl>

Presets

Reeded has 14-DIP ribs; Fine has 6-DIP ribs that bend less; Frosted is reeded glass frosted at 0.6; Wide has 32-DIP ribs that bend further, with a stronger color split. A preset applies at template priority, so a local value wins over it.

Value Description
Reeded (default) Medium ribs in clear glass: the classic reeded pane.
Fine Narrow ribs with a gentle bend.
Frosted Medium ribs in frosted glass.
Wide Broad ribs with a strong bend and more color split.

Give it something to bend

Fluted glass copies the region of the window behind the host just before it draws (see Layers that read the backdrop). So:

  • Something must be behind it: the page's background, earlier siblings in a Grid, a picture or a list. Over a flat color the ribs have nothing to squeeze, and only their sheen and grooves show. Text and sharp shapes behind it show the flip best.
  • Keep the child see-through. The glass draws under the child, so a Background on the child hides it. Text on the child stays sharp on top of the ribs.
  • Keep ancestors opaque. Inside an offscreen layer (an ancestor with Opacity below 1, an effect, or a clip that needs a layer) the copy can't see that ancestor's content.

Turn, frost and tint the ribs

Angle turns the ribs (0 is upright, 90 lies them flat), Rib sets their width and Refraction how far each one bends the image sideways. Frost, Tint and TintAmount frost and color the glass:

<fx:FlutedGlass Angle="90" Rib="10" Refraction="6" Frost="0.3" Tint="#FFFFFF" TintAmount="0.15" />

Like the other fills, fluted glass also has BorderWidth, which keeps the ribs to a band inside the edge, and UseMask (see Content masks).

Properties

Property Type Default Description
Preset FlutedGlassPreset Reeded A starting set of Rib, Refraction, Frost and Dispersion; local values win. Values: Reeded, Fine, Frosted, Wide.
Rib double 14 Width of a rib, in DIPs. Range 2–64.
Angle double 0 Direction of the ribs, degrees: 0 upright; positive turns them clockwise. Range -180 to 180.
Refraction double 9 How far each rib bends the image sideways, DIPs. Range 0–40.
Frost double 0 How frosted the glass is: 0 clear, 1 a soft blur with lifted, richer color. Range 0–1 (0–100%).
Dispersion double 0.15 Color split toward the rib edges. Range 0–1 (0–100%).
Highlight double 0.5 Sheen along each rib's lit side. Range 0–1 (0–100%).
Tint Color #FFFFFF A color the glass multiplies what is behind it by, as much as TintAmount says.
TintAmount double 0 How much Tint colors the glass (0: clear). Range 0–1 (0–100%).
BorderWidth double 0 Width of a band inside the edge, DIPs. 0: the whole shape. Range 0–48.
UseMask bool false Paints only the child's own pixels (text, icons, a logo) instead of the shape: gradient text, a liquid-metal logo, holographic icons. It then goes over the child unless Placement says otherwise. The host captures the child to know its pixels: call RefreshMask after changing something deep inside it.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale. As on every fill, Intensity is the coverage, up to 1. Fluted glass is still, so Speed and Seed don't apply.

Notes

  • Light and dark surfaces: it draws the same on both. Pick a Tint per theme with a theme resource (see Light and dark surfaces).
  • Reduced motion: fluted glass has no motion of its own, so nothing changes.
  • Cost: about 0.17 ms of GPU time a frame on the benchmark card, plus one copy of the region behind it. It doesn't animate: it redraws when what is behind it changes. See Performance.
