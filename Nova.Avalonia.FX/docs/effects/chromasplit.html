Chroma split

ChromaSplit pulls the red and blue channels apart from green, so edges pick up red and blue fringes, as on a misaligned screen or a cheap lens. With GlitchRate, thin slices now and then jump sideways. Use it on a bold heading, a tech or retro title, or as a hover accent. It draws over the child and works on what is drawn there: the child, and whatever shows through it.

  • Light
  • Dark

Add a chroma split

Wrap the content in a host. OffsetX and OffsetY set how far red and blue move, in opposite directions:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost>
        <fx:FXHost.Layers>
            <fx:ChromaSplit OffsetX="2" />
        </fx:FXHost.Layers>
        <TextBlock Text="Nova FX" FontSize="40" FontWeight="Bold" />
    </fx:FXHost>
</UserControl>

Add glitch slices

GlitchRate is how often slices jump sideways, from 0 (never) to 1:

<fx:ChromaSplit OffsetX="3" GlitchRate="0.4" />

With slices, the layer animates and Seed and Speed apply; without them it is still and draws once.

Split on hover

Animate the offset from a style, so the colors pull apart while the pointer is over a host with Classes="title". Leave OffsetX unset on the layer itself, since a local value wins over a style:

<Style Selector="fx|FXHost.title fx|ChromaSplit">
    <Setter Property="OffsetX" Value="0" />
    <Setter Property="Transitions">
        <Transitions>
            <DoubleTransition Property="OffsetX" Duration="0:0:0.2" />
        </Transitions>
    </Setter>
</Style>
<Style Selector="fx|FXHost.title:pointerover fx|ChromaSplit">
    <Setter Property="OffsetX" Value="3" />
</Style>

Give it sharp edges

The split copies what is under it just before it draws (see Layers that read the backdrop): the child, and whatever shows through it. Content with sharp, high-contrast edges, such as bold text or icons, shows the fringes best; a flat fill shows nothing. Controls drawn after the host aren't split. Inside an offscreen layer (an ancestor with Opacity below 1, an effect, or a clip that needs a layer) the copy can't see that ancestor's content, so keep such ancestors opaque.

Properties

Property Type Default Description
OffsetX double 2 How far red moves left and blue moves right, in DIPs; negative swaps them. Range -16 to 16.
OffsetY double 0 How far red moves up and blue moves down, in DIPs; negative swaps them. Range -16 to 16.
GlitchRate double 0 How often slices jump sideways (0: never). Range 0–1 (0–100%).
Feather double 2 How soft the layer's edge is, in DIPs. Range 0–16.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale.

Notes

  • Light and dark surfaces: it draws the same on both.
  • Reduced motion: the slices stop jumping; the split itself stays.
  • Cost: about 0.11 ms of GPU time a frame on the benchmark card. Without GlitchRate it doesn't animate, so it only redraws when what is under it changes. See Performance.
