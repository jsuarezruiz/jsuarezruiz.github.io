Shimmer

A soft band of light sweeps across the shape once a period, then rests off it before the next pass. Use it for skeleton loaders, a button that is working, or a "Thinking…" label while an answer streams in. It draws over the host's child, and the band starts and ends off the shape, so it never cuts in or out mid-pass. With UseMask, it sweeps across the child's own pixels instead of its box.

  • Light
  • Dark

Add a shimmer

Wrap the control in an FXHost and add a Shimmer to its layers:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost>
        <fx:FXHost.Layers>
            <fx:Shimmer />
        </fx:FXHost.Layers>
        <Button Classes="accent" Content="Generate" />
    </fx:FXHost>
</UserControl>

Build a skeleton loader

BaseColor paints a block under the sheen, so an empty Border becomes a placeholder bar. Each bar needs its own host and its own layer, since a layer can be in one host at a time:

<StackPanel Spacing="12" Width="240">
    <fx:FXHost CornerRadius="8">
        <fx:FXHost.Layers>
            <fx:Shimmer BaseColor="#E2E5EA" Intensity="1.6" />
        </fx:FXHost.Layers>
        <Border Height="16" />
    </fx:FXHost>
    <fx:FXHost CornerRadius="8" HorizontalAlignment="Left">
        <fx:FXHost.Layers>
            <fx:Shimmer BaseColor="#E2E5EA" Intensity="1.6" />
        </fx:FXHost.Layers>
        <Border Height="16" Width="130" />
    </fx:FXHost>
</StackPanel>

BaseColor is a Color, so a theme resource bound to it must be a color resource, not a brush. Transparent (the default) paints no block.

To switch the placeholder off when the data arrives, bind IsActive. Layers inherit the host's DataContext:

<fx:Shimmer BaseColor="#E2E5EA" IsActive="{Binding IsLoading}" />

Sweep across text

With UseMask, the sheen runs over the letters only, not the text's whole box. A gray text color lets it show on both light and dark themes:

<fx:FXHost>
    <fx:FXHost.Layers>
        <fx:Shimmer UseMask="True" Intensity="2.5" Band="18" />
    </fx:FXHost.Layers>
    <TextBlock Text="Thinking…" FontSize="16" FontWeight="SemiBold" Foreground="#8A8F98" />
</fx:FXHost>

The host captures its child to find those pixels. After changing something deeper inside the child, call FXHost.RefreshMask(); see Content masks.

Shape the sweep

Period is the length of one pass plus its rest, in seconds, and Pause is the share of it the band spends off the shape. Band sets the band's width, Angle tilts it from upright, and Color tints it:

<fx:Shimmer Period="2.4" Pause="0.5" Band="40" Angle="-15" Color="#BFDBFE" />

Feather softens the edge of the shape. It doesn't apply with UseMask, which follows the child's own edges.

Properties

Property Type Default Description
Color Color #FFFFFF The sheen's color.
BaseColor Color #00FFFFFF A base color under the sheen (a skeleton block). Transparent: none.
Period double 1.8 Seconds from one sweep to the next, pause included. Range 0.3–6.
Band double 28 Width of the sheen band, in DIPs. Range 4–120.
Angle double 20 Tilt of the band from upright, degrees: 0 upright; positive turns it clockwise (top to the right). Range -60 to 60.
Pause double 0.3 Share of each period the band rests off the shape. Range 0–0.9 (0–90%).
Feather double 0 How far inside the shape's edge the sheen fades in, in DIPs (0: a crisp edge). Not used with UseMask. Range 0–24.
UseMask bool false Sweep across the child's own pixels (text, icons) instead of its box.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale.

Notes

  • Intensity is the sheen's strength, up to 3. At 0 the sheen is gone, but a BaseColor block still draws. Seed doesn't change the shimmer.
  • Light and dark surfaces: the shimmer draws the same on both. The sheen adds light, so it shows over colored or darker content and has little to brighten on plain white; give a skeleton a BaseColor, and text a gray or colored foreground.
  • Reduced motion: the band stops traveling, and the whole surface breathes gently instead. See Reduced motion.
  • Cost: 0.025 ms of GPU time per frame on a 340×190 card, in the gallery's bench. See Performance.
