Reveal

Reveal shows and hides the host's content with a transition: it dissolves into noise, burns away, closes in an iris, melts out of its place, or resolves out of noise like an image being generated. Use it wherever content arrives or goes away: a panel that opens, a draft that's discarded, a result that comes in. The layer captures the content as it looks, hides the real element, and plays the transition over it.

  • Light
  • Dark

Add a reveal

Bind IsShown to whatever says the content should be there. Here a switch burns a card away and back:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <StackPanel Spacing="12" HorizontalAlignment="Center" VerticalAlignment="Center">
        <fx:FXHost CornerRadius="14">
            <fx:FXHost.Layers>
                <fx:Reveal Style="Burn" IsShown="{Binding #ShownSwitch.IsChecked}" />
            </fx:FXHost.Layers>
            <Border Width="200" Height="96" CornerRadius="14" Padding="16" Background="#15171c">
                <TextBlock Text="Draft" Foreground="White" FontWeight="SemiBold" />
            </Border>
        </fx:FXHost>
        <ToggleSwitch x:Name="ShownSwitch" IsChecked="True" OnContent="Shown" OffContent="Burned" />
    </StackPanel>
</UserControl>

Styles

Style picks the transition. Softness, EdgeColor, Angle, NoiseScale, CellSize and Twist each belong to some styles; the properties table lists which.

Value Description
Dissolve (default) The content breaks up into noise; on a dark surface its edge catches a faint light.
Burn A dissolve with a glowing, charring edge.
Pixelate The content coarsens into blocks, then fades.
Iris A circle closes on (or opens from) the origin.
Wipe A soft edge sweeps across.
Melt The content melts and drips down out of its place.
Radial A hand sweeps around the origin, like a clock.
Diamonds Diamonds grow in a grid, in a wave across.
Swirl The content twists in from a swirl as it fades in, and out into one.
Halftone Halftone dots grow into the content, in a wave across.
Generate Noise resolves into the content in ever finer steps, as an image being generated.

Show and hide

IsShown is true by default and binds both ways, so Show() and Hide() also update a bound view-model property. Set IsShown="False" in XAML to start hidden: the content is hidden at once, with no transition.

While hidden, the element is transparent but keeps its place in the layout. Its own Opacity value is left alone, and it still takes clicks and keyboard focus; set IsHitTestVisible from the same property if it shouldn't. A change while a transition plays turns it around from where it is, without a jump. The capture is taken as the transition starts, so changes to the content show once it is handed back.

Play it from a point

Show(from) and Hide(toward) take a point in the host's coordinates. An iris opens from it or closes on it, a clock wipe (Radial) sweeps around it, and a swirl twists around it. With no point they use the center of the shape; the other styles ignore the point.

private void OnCardReleased(object? sender, PointerReleasedEventArgs e)
{
    // Close the iris on the point that was tapped.
    CardReveal.Hide(e.GetPosition(CardHost));
}

Drive it from a view model

Bind IsShown to a property and change the property:

// ViewModelBase is any base class that raises PropertyChanged,
// such as CommunityToolkit.Mvvm's ObservableObject.
public class ComposerViewModel : ViewModelBase
{
    private bool _isDraftShown = true;

    public bool IsDraftShown
    {
        get => _isDraftShown;
        set => SetProperty(ref _isDraftShown, value);
    }

    public void Discard() => IsDraftShown = false;

    public void Undo() => IsDraftShown = true;
}

<fx:Reveal x:Name="CardReveal" Style="Dissolve" IsShown="{Binding IsDraftShown}" />

Because the binding is two-way, a Hide(point) called from the view also sets IsDraftShown to false.

Set the pace

Duration is the length of one transition in seconds (0.8 by default). The layer's Speed doesn't apply. The length is read when a transition starts, so a change applies from the next one; under reduced motion it is at most a quarter of a second.

Before the content is laid out

A transition needs a capture of the content. With nothing to capture, the layer switches at once without playing: when the host has no child, the child isn't visible, it hasn't been laid out yet (for example, IsShown set in a view's constructor), or the layer's IsActive is false. To play an entrance as a view opens, start hidden and call Show() once the content is laid out:

<fx:Reveal x:Name="WelcomeReveal" Style="Generate" Duration="1.6" IsShown="False" />

public WelcomeView()
{
    InitializeComponent();
    // Loaded is raised after the view's first layout pass.
    Loaded += (_, _) => WelcomeReveal.Show();
}

Methods

Show and Hide play the transition from code, from or toward a point.

Method Description
Show(Point? from = null) Shows the content, playing the layer's transition from from (host coordinates). Null: the layer's own point.
Hide(Point? toward = null) Hides the content, playing the layer's transition toward toward (host coordinates). Null: the layer's own point.

Properties

Property Type Default Description
Style RevealStyle Dissolve How the content appears and disappears. Values: Dissolve, Burn, Pixelate, Iris, Wipe, Melt, Radial, Diamonds, Swirl, Halftone, Generate.
IsShown bool true Whether the content is shown. Changing it plays the transition: true reveals the content, false hides it.
Duration double 0.8 How long the transition takes, in seconds. Range 0.1–4.
Softness double 0.06 Softness of the edge, as a share of the transition. Range 0.01–0.4 (1–40%). Applies to the Dissolve, Burn, Iris, Wipe, and Radial styles.
EdgeColor Color #FF8A2A The burning edge's color. Applies to the Burn style.
Angle double 0 Direction a wipe, or the wave of diamonds or dots, sweeps (0: left to right); where a clock wipe starts (0: at the top). Degrees; positive turns clockwise. Range -180 to 180. Applies to the Wipe, Radial, Diamonds, and Halftone styles.
NoiseScale double 26 Grain of a dissolve or burn; the width of a melt's drips. Range 4–120 DIPs. Applies to the Dissolve, Burn, and Melt styles.
CellSize double 28 The coarsest block of a pixelate or a generate; the grid of diamonds or dots. Range 4–80 DIPs. Applies to the Pixelate, Diamonds, Halftone, and Generate styles.
Twist double 300 How far a swirl twists the middle of the content, degrees (0: not at all); it turns counterclockwise as it hides. Range 0–1080. Applies to the Swirl style.

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale.

Notes

  • Light and dark. Reveal knows the surface it sits on: on a dark one, a dissolve's edge catches a faint light. See Light and dark surfaces.
  • Reduced motion. Every style becomes a fade of at most a quarter of a second. See the poses.
  • Cost. Each transition renders the content once into an image on the UI thread. While it plays, a reveal takes about 0.1 ms of GPU time a frame on a card (the melt 0.12 ms). Once shown and handed back, or hidden, it draws nothing. See What a layer costs.
  • Room below a melt. Melt runs down past the content's bottom edge. Leave room below the host, or a clipping ancestor cuts the drips.
  • Contrast. A dissolve reads by what shows through its holes. Content with the same color as the surface behind it needs an edge or a border to show the transition.
