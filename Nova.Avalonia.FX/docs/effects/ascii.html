ASCII

ASCII art, live: the layer redraws the host's content, and anything under the host, as rows of text characters, picking for each cell the character whose ink matches the brightness there, from a blank through .-:+=%*# to @. The characters take the content's own colors, or one ink. Use it for terminal and hacker themes, a stylized picture, or a playful hover state. It goes over the child and follows whatever is drawn there, so a picture, a gradient or a video works best.

  • Light
  • Dark

Add ASCII

Put the layer over content with a range of tones, such as a picture or a gradient:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost CornerRadius="14">
        <fx:FXHost.Layers>
            <fx:Ascii CellSize="6" />
        </fx:FXHost.Layers>
        <Border Width="236" Height="128" CornerRadius="14">
            <Border.Background>
                <LinearGradientBrush StartPoint="0%,0%" EndPoint="100%,100%">
                    <GradientStop Color="#7C3AED" Offset="0" />
                    <GradientStop Color="#EC4899" Offset="0.55" />
                    <GradientStop Color="#F59E0B" Offset="1" />
                </LinearGradientBrush>
            </Border.Background>
        </Border>
    </fx:FXHost>
</UserControl>

Bright areas get dense characters and dark areas blanks, on a dark paper.

Choose the ink and the paper

By default each character takes the content's own color. Turn IsColored off to draw every character in InkColor, like a terminal. PaperColor fills the cells behind the characters; set it to Transparent to show the page instead:

<fx:Ascii IsColored="False" InkColor="#4ADE80" PaperColor="#0B0D10" />

For dark ink on light paper, set IsInverted, so the darkest areas get the densest characters:

<fx:Ascii IsColored="False" IsInverted="True" InkColor="#1F2937" PaperColor="#F9FAFB" />

Size the characters

CellSize is the width of a character cell in DIPs; cells are 1.6 times as tall. Smaller cells show more detail. Contrast spreads the brightness, so more of the picture reaches the densest and the emptiest characters:

<fx:Ascii CellSize="10" Contrast="1.6" />

Fade it in on hover

Intensity fades the layer, so a transition on it turns content into text and back. This shows the picture, and turns it to ASCII while the pointer is over it:

<Style Selector="fx|FXHost.ascii fx|Ascii">
    <Setter Property="Intensity" Value="0" />
    <Setter Property="Transitions">
        <Transitions>
            <DoubleTransition Property="Intensity" Duration="0:0:0.3" />
        </Transitions>
    </Setter>
</Style>
<Style Selector="fx|FXHost.ascii:pointerover fx|Ascii">
    <Setter Property="Intensity" Value="1" />
</Style>

Give the host Classes="ascii". At an Intensity of 0 the layer draws nothing and costs nothing.

Properties

Property Type Default Description
CellSize double 7 The width of a character cell; cells are 1.6 times as tall. Range 4–24 DIPs.
IsColored bool true The characters take the content's own color instead of InkColor.
InkColor Color #E5E7EB The characters' color when IsColored is off. Applies when IsColored is false.
PaperColor Color #0B0D10 Behind the characters; transparent shows the page.
Contrast double 1.2 How far the brightness is stretched before a character is picked: above 1 pushes cells toward blank or dense, below 1 toward the middle of the ramp. Range 0.2–3.
IsInverted bool false Dark areas get the densest characters (for dark ink on light paper).

Every layer also has the common properties: Intensity, Opacity, Speed, Seed, IsActive, Placement, BlendMode and RenderScale.

Notes

  • Reads the backdrop: the layer copies what is drawn behind it, the child included, just before it draws, and each cell takes the average under it. Keep ancestors opaque; see Layers that read the backdrop.
  • Needs room: on a small control the cells swallow a label. Use it on cards, panels and pictures.
  • Still: the layer has no motion of its own; it changes only when what is behind it does. Speed and Seed don't change it, and reduced motion leaves it as it is.
  • Light and dark surfaces: it draws the same on both; PaperColor and IsInverted set the look.
  • Cost: 0.272 ms of GPU time per frame on a 340×190 card in the gallery's bench, plus a blurred copy of what is behind it. See Performance.
  • The characters are small dot shapes made in the shader, not a font, so no font needs to be installed.
