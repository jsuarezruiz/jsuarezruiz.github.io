Reduced motion

Every layer has a reduced-motion pose: a calm version of the effect with no travel. One switch turns it on for the whole app.

Turn it on

Set FXSettings.ReducedMotion:

using Nova.Avalonia.FX;

FXSettings.ReducedMotion = true;

Every host updates its layers before the next frame. The setting can change at any time, from any thread; the hosts rebuild their layers on the UI thread.

Avalonia doesn't report a system reduced-motion preference, so the app decides. Set it from your app's own setting, for example a switch on a settings page:

<ToggleSwitch x:Name="ReduceMotionSwitch"
              Content="Reduce motion"
              IsCheckedChanged="OnReduceMotionChanged" />

private void OnReduceMotionChanged(object? sender, RoutedEventArgs e)
{
    FXSettings.ReducedMotion = ReduceMotionSwitch.IsChecked == true;
}

The poses

Under reduced motion, layers keep their look but stop traveling:

Layers Reduced-motion pose
Glow and other lights Lights still cool when switched off: a fade, not travel.
Pulse The rings become a static halo.
Fills: gradients, materials, patterns and backgrounds Each holds one fixed pose.
Shimmer The surface breathes instead of sweeping.
Aurora, grain, light leaks, light rays, fog, topography, particle network, rain on glass, border beam They hold still.
Beam A still gradient along the path.
Old film It holds one frame.
Voice orb, voice wave The colors and waves hold still; they still swell with Level.
Fire The flames hold one pose and the embers stop; the simulated styles hold their current state.
Electric The continuous bolt holds one shape; a zap still strikes.
Reveal, Genie, Shatter A short fade, at most a quarter of a second.
Spoiler It switches at once.
Confetti, fireworks The pieces appear in place and fade, without flying.
Glitch A burst is a short, mild color split; a continuous glitch stays still.
Jelly A small, quick squash.
Page peel A quick peel.
Tilt The host stays flat; only the glare follows the pointer.
Trail No trail: it only exists as motion.
Motion blur No smear: the host still moves, but nothing is drawn behind it.
Ink The ink stays where it lands and fades.
Water Gentler ripples and splashes, and no rain.
Liquid progress The level jumps, and the surface stays calm.
Dot grid The lit dots jump to the pointer, and presses send no ripples.
Spotlight, magnifier and other pointer layers They jump to the pointer instead of easing, and appear and fade at once.

A transition's length is decided when it starts, so switching reduced motion halfway through doesn't put it out of step.

Check the poses

In the gallery, the settings flyout switches motion between full and reduced. The desktop gallery also renders the poses headless:

dotnet run --project samples/Nova.Avalonia.FX.Gallery.Desktop -- --snap reduced.png --reduced --effect glow

Fixed time

Separately from reduced motion, FXSettings.Clock replaces the compositor clock for every layer, in seconds. Every frame is a pure function of time, so the same time always draws the same frame. Use it for deterministic snapshots and for stepping through an effect:

FXSettings.Clock = () => 2.3;   // every layer draws as it looks 2.3 s in
FXSettings.Clock = null;        // back to the compositor clock
