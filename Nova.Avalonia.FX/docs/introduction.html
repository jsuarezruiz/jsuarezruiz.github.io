Nova.Avalonia.FX
Table of Contents

Introduction

Nova.Avalonia.FX adds GPU effects to Avalonia controls. You wrap a control in an FXHost and give the host one or more layers. Each layer is an SkSL shader (or, for a few, shapes drawn with Skia) that the host draws under the control, like a glow or a background, or over it, like a sheen, grain or a ripple.

The layers run on the composition render thread and only ask for frames while something moves. A layer with nothing to animate, a hidden host and a host scrolled out of view cost nothing.

Highlights

  • 70 layers in 12 groups: light, surface, materials, gradients, patterns, color, shape, glass, distortions, moments, depth and backgrounds. The home page lists them all.
  • Lights that cool: a Glow switched off shrinks, deepens and dims instead of cutting off, and on a light surface light layers draw as tinted haze instead of vanishing into white.
  • Effects that follow the content: a mask glow, a text shimmer, gradient text, an Outline or an InnerShadow follow the child's own pixels, not just its box.
  • Glass and distortions: Glass, frost, rain, water and the distortions bend and blur what is drawn behind them.
  • Moments: one-shots such as ripples, confetti and fireworks that overlap, and transitions such as Reveal, Shatter and Genie that show and hide the content.
  • Ordinary Avalonia properties: layers are styled elements, so styles, bindings, dynamic resources and transitions apply to them like any other property.
  • A catalog: FXCatalog describes every layer with its parameters, ranges and choices, and writes a layer back as XAML.
  • Reduced motion: every layer has a calm pose, switched on for the whole app with FXSettings.ReducedMotion.

How to use these docs

  • Start with Getting Started to install the package and put a first layer on a control.
  • Read the Concepts pages for how hosts and layers work: placement, light and dark surfaces, content masks, one-shots, reduced motion and performance.
  • Browse the pages under Effects for each layer's settings and examples.
  • Refer to the API reference for every class and member.
  • Try the effects in the gallery, which also shows each layer's XAML as you change its settings.
