Getting Started

Follow these steps to install Nova.Avalonia.FX, wrap a control in an FXHost and give it its first layers.

Prerequisites

  • Avalonia 12.1.5 or later in the Avalonia 12 release line, with the Skia renderer (the default)
  • .NET 8 or later

The layers draw on the desktop and in the browser (WebAssembly, with WebGL). On another rendering backend they draw nothing rather than fail.

Install the NuGet package

The package is in preview, so include prerelease versions. From your application project:

dotnet add package Nova.Avalonia.FX --prerelease

There are no styles to register. The library has no control templates: FXHost is a plain control and the layers are styled elements, so nothing needs to go in Application.Styles.

Declare the XAML namespace

Every layer, the host and the catalog are in one XAML namespace. Map it to the fx prefix:

xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX"

Wrap a control in an FXHost

FXHost takes one child and draws its layers around it. Add layers to FXHost.Layers. This puts a neon glow around a card:

<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:fx="https://github.com/jsuarezruiz/Nova.Avalonia.FX">

    <fx:FXHost HorizontalAlignment="Center" VerticalAlignment="Center">
        <fx:FXHost.Layers>
            <fx:Glow Style="Neon" Color="#22d3ee" />
        </fx:FXHost.Layers>
        <Border Width="220" Height="96" CornerRadius="14" Background="#101217" />
    </fx:FXHost>
</UserControl>

The layers follow the child's bounds and corner radius. The host reads the corner radius from a Border or a templated control; for anything else, or to override it, set FXHost.CornerRadius. CornerRadius="999" makes a capsule or a circle.

A glow spills past the child, and it is drawn outside the host's bounds. A clipping ancestor cuts it: a ScrollViewer, a Border with ClipToBounds, or Fluent's ContentControl, which clips by default. Leave room around the host, or set ClipToBounds="False" where that is safe.

Stack several layers

A host can hold any number of layers. Each one draws under the child or over it (its placement), and within each placement they paint in the order you list them. Here a liquid-metal fill goes under the label and sparkles go over it:

<fx:FXHost CornerRadius="26">
    <fx:FXHost.Layers>
        <fx:LiquidMetal Preset="Gold" />
        <fx:Sparkles BurstOnPress="True" IsContinuous="False" />
    </fx:FXHost.Layers>
    <Border Padding="40,14">
        <TextBlock Text="Upgrade" />
    </Border>
</fx:FXHost>

The sparkles only show when the host is pressed, because IsContinuous is off and BurstOnPress is on. Layers and hosts explains placement, blend modes and the properties every layer shares.

Set properties

Layer settings are Avalonia styled properties, so you can set them in XAML, bind them, take them from resources and animate them:

<fx:Glow Style="Neon"
         Color="{DynamicResource SystemAccentColor}"
         IsLit="{Binding IsOnline}"
         Cool="0.8" />

Switching IsLit off cools the glow over Cool seconds instead of cutting it off.

Styles reach layers too. This fades a glow up while the pointer is over the host:

<Style Selector="fx|FXHost.hover fx|Glow">
    <Setter Property="Intensity" Value="0.2" />
    <Setter Property="Transitions">
        <Transitions>
            <DoubleTransition Property="Intensity" Duration="0:0:0.3" />
        </Transitions>
    </Setter>
</Style>
<Style Selector="fx|FXHost.hover:pointerover fx|Glow">
    <Setter Property="Intensity" Value="1.3" />
</Style>

From code, create a host and its layers like any other control:

using Avalonia;
using Avalonia.Controls;
using Avalonia.Media;
using Nova.Avalonia.FX;

var host = new FXHost
{
    CornerRadius = new CornerRadius(14),
    Child = new Button { Content = "Generate" },
};
host.Layers.Add(new Glow { Style = GlowStyle.Neon, Color = Color.Parse("#22d3ee") });

A layer can be in one host at a time. Adding a layer that is still in another host's Layers throws an InvalidOperationException.

Fire a one-shot from code

Some layers play a moment when asked: a ripple, a burst of confetti, a zap. Name the layer and call its method. Points are in the host's coordinates; leave them out to use the layer's own spot.

<fx:FXHost>
    <fx:FXHost.Layers>
        <fx:Confetti x:Name="Celebration" />
    </fx:FXHost.Layers>
    <Button Content="Save" Click="OnSave" />
</fx:FXHost>

private void OnSave(object? sender, RoutedEventArgs e)
{
    Celebration.Fire();
}

Most one-shot layers can also fire on a press of the host, such as Confetti.FireOnPress or Pulse.TriggerOnPress. One-shots and the pointer lists them all.
