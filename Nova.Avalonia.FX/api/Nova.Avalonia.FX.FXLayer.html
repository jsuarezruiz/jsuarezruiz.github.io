Class FXLayer

Namespace
Nova.Avalonia.FX

Nova.Avalonia.FX.dll

Base class of every layer. A layer is a pure function of (position, parameters, time, seed): no hidden state and no randomness, so a given time always renders the same frame. Layers are styled elements: they take part in styles, bindings and transitions, so a style setter on Intensity with a DoubleTransition animates a glow smoothly on hover. A layer is in one FXHost at a time: adding it to a second host's Layers throws until it is removed from the first.

RenderScaleProperty

Shades at this fraction of the display's resolution and scales the result up: 0.5 shades a quarter of the pixels. For large, soft layers (a window-sized aurora or swirl), where the cost grows with the area; edges and grain soften. 1 (the default) is full resolution.

public static readonly StyledProperty<double> RenderScaleProperty

Invalidate()

Asks the host for a fresh snapshot (a change that is not a property, such as a ping's destination). Unlike a property change it is sent at once, in the same UI tick, so a layer that takes over from the content (a reveal) and the content itself never disagree for a frame.
