Parameters

Layer string

The layer's type name.

Draws int

Draws recorded (a layer with one-shots may draw several instances a frame).

CpuMs double

Render-thread time spent setting up and issuing the draws (uniforms, backdrop copies, draw calls); the state's per-frame work is PrepMs.

GpuMs double

GPU time of the draws (only with MeasureGpu).

Pixels double

Pixels shaded.

FirstDrawMs double

The first draw of this layer type in the process, start to finish on the GPU: shader and pipeline compiles included (only with MeasureGpu).

PrepMs double

Render-thread time the layer's state spent preparing its frames: simulations stepped, one-shots and tables updated, before any draw.
