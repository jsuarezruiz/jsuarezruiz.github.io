Class ColorFilter

Namespace
Nova.Avalonia.FX
Assembly
Nova.Avalonia.FX.dll

CSS-style color filters, live, within the shape: over the child (the default) they recolor the child and whatever shows through it, as CSS filter does; under it (Placement Under) they recolor what is behind the host, as backdrop-filter does. With UseMask only the child's own pixels change (an icon, not the card around it). Brightness, contrast, saturation, hue, grayscale and sepia use CSS's formulas; Intensity is how much of the filter shows. Disabled states, "grayscale until hover", styled photos, images dimmed in dark mode. It starts as grayscale (Preset).
