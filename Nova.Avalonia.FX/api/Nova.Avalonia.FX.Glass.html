Class Glass

Namespace
Nova.Avalonia.FX
Assembly
Nova.Avalonia.FX.dll

A pane of liquid glass over what is behind the host: a beveled rim that refracts and splits the backdrop, a little magnification, an optional frost, a specular rim facing the light and a soft drop shadow. It reads what is drawn behind it, so it follows anything that moves there.
