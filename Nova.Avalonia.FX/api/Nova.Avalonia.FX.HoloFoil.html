Class HoloFoil

Namespace
Nova.Avalonia.FX
Assembly
Nova.Avalonia.FX.dll

Holographic foil over the shape: an iridescent rainbow sheen whose bands shift as the pointer moves over it, fine etched lines, glitter that flares as the angle passes each facet, and a soft glare under the pointer. Still when the pointer is away (unless it drifts), so idle it costs nothing.
